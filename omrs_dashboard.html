📥 导入反馈：答题卡扫描 / 屏幕版 / AI

答题卡：先在上面选中这张卡对应的 Session，在 OMR 识别详情页点击「复制结果 JSON」； 该内容来自 /api/v1/recognitions/<id>/result，顶层含 recognition_id / template_id / mode / status / questions / unresolved。 回到本页点「📋 读剪贴板填写」，也可以在本页空白处直接按 Ctrl/⌘+V。 题号按 Session 的题目顺序对应 UID，与 A4 导出打印的「第 N 题」是同一个顺序。
屏幕版：复习完后在「作答情况」抽屉点「复制作答 JSON」并粘贴。 AI：先复制提示词，把纸面批改结果或口述反馈发给 AI，让它整理成同一份反馈 JSON 后粘贴。

只接受上述 /result 顶层协议；旧的原始识别记录 items、裸数组和包装层会明确拒绝。 unresolved 涉及的题不会自动猜测，字段与状态会写进备注并留给你人工判定。 导出答题卡之后又停用过题目的话，纸面题号会整体前移——提交前请对着中栏题面核一遍。

🎨 外观
首次打开默认深色（暖石墨）；题目截图多为浅色，白天可切浅色阅读。设置保存在本浏览器。
紧凑档统一收紧内边距、圆角、行高和控件高度（题库表格一屏多约 10 行）。功能复杂的页面——题库、反馈工作台、收件箱处理——默认就按紧凑排版，这里只影响全站基准。
简易反转：白底变黑、黑字变白（filter: invert(1)），让浅色截图在深色下不刺眼。仅深色模式生效，彩色会一并反相，后续可再做智能保色。
Ledger 继续以 UTC 保存，切换只影响「历史记录」与仪表盘「最近动态」的显示。设置保存在本浏览器，无需重启。
⚙️ 服务设置
开启后，其他设备可通过本机的局域网 IP（如 192.168.x.x:端口）访问；本机始终用 127.0.0.1。不要在浏览器输入 0.0.0.0（它只是「监听所有网卡」的占位地址，无法访问）。修改后需重启生效，启动时控制台会打印可访问的网址。
