# 2026-09-13 架构改造第 6 期：迁目录页与数据页

## 变更摘要

两个「读多写少、交互简单」的页面迁到组件层，把组件层的**数据获取**与**图表渲染**两种
模式定下来。删掉 assets/catalog.js（232 行）与 assets/data.js（165 行），
面板换成 island + 「尚未构建」兜底卡片，形态与第 5 期报告页完全一致。

**目录页**：`web/src/CatalogPanel.vue` + 递归组件 `web/src/components/CatalogNode.vue`。
树的结构仍来自 `GET /api/tree`，学习状态仍按路径前缀从 `DATA.items` 聚合，
后端不可用时仍退回按 `File_Path` 推算的树——口径一个字没改。
展开 / 折叠 / 搜索从「整树 `innerHTML` 重绘」变成局部更新。

**数据复盘页**：`web/src/DataPanel.vue` + 八个展示组件（`StatGrid` / `BarList` /
`DataTable` / `SubjectRadar` / `DiffMasteryScatter` / `HourHeatmap` / `TrendChart` /
`LabelDist`）。迁移前是一次性往 20 多个 id 里 `innerHTML`，改一处很难知道碰坏了哪块；
现在是一个 `analytics` ref 加一串 computed，块与块之间不再靠 id 耦合。
所有阈值、分箱、配色逐字沿用。

**图表选型**：按计划「继续手写 SVG，不引图表库」。现有图表已经和 token 层绑定，
引库会带来第二套配色体系。雷达图与散点图的几何算法原样搬进 computed。

## 三处与计划不同

### 1. 共享 store 从第 7 期提前到第 6 期，并且改成单向

计划把 reactive store 排在第 7 期。但本期两个页面都要读 `DATA`——目录页要聚合学习状态，
数据页要接手趋势图与标记分布——所以必须先有它。

改动比计划更小：计划写的是「store 做双向同步桥，遗留脚本继续读写同名全局」。
实际做成**单向镜像**：`reloadData()` 末尾派发 `omrs:data`，`web/src/store.js` 订阅后
把 `window.DATA` / `window.SESSIONS` 拉进 `shallowRef`；组件从不回写这些全局，
要改数据就调后端再让 `reloadData()` 跑一遍。

单向是够用的——已迁的两页都只读；后面几页写的是各自的局部状态（`INSTANT_*`、`REC_*`、
`fbRows`），不是 `DATA`。少一个方向意味着写路径只有一条，也意味着第 11 期要拆的东西少一半。
`tests/test_p6_islands.py` 有一例专门盯着 store 不回写。

`shallowRef` 而不是 `reactive`：`DATA.items` 动辄上千条，而它每次是整个换掉的，
深层代理只会白花时间。

### 2. 两张图连函数带容器一起搬家

`#chart-trend` 与 `#chart-labels` 在 `panel-data` 里，但 `renderTrendChart()` /
`renderLabelChart()` 在 `assets/dashboard.js`，由 `renderDash()` 调用——v1.15.0
把分布类图表搬到复盘页时只搬了容器，函数留在了仪表盘那边。

容器归 island 之后，遗留脚本再往里写就写进了已被 Vue 换掉的旧节点：**页面不报错，
图就是不出来**。所以这两个函数连同只服务于它们的 `dashSmoothPoints` 一起从
`dashboard.js` 删除，改成 `TrendChart.vue` / `LabelDist.vue`。

这是本期最值得记的一条，因为它是**通用形态**：迁一个面板之前，必须先查有没有别的遗留
脚本往这个面板里写。已经写进 `AI/frontend.md` §14「再迁一个页面」的第 5 步。

### 3. `cssCodeSplit` 从关改成开

第 5 期只有一个入口，`cssCodeSplit: false` 无所谓。现在有三个：关着的话三份 scoped
样式会合并成一个文件，谁引都得引全部。打开后每个入口出一对 `<入口名>.js` / `.css`。

## 行为与兼容性

- 两页的功能与迁移前逐项一致。目录页额外区分了「加载中 / 还没加载」两种状态；
  数据页的状态行多了导出成功的回显（迁移前 `downloadExportResponse` 直接写 `#data-status`，
  组件没有 `statusId` 可传，改用第 5 期加的返回值）。
- `switchTab()` 里对 `loadAnalytics()` / `loadCatalog()` 的直呼删除，改由 `omrs:tab` 懒加载，
  时机与迁移前一致。`reloadData()` 里「目录页激活就重画」那一支删除，改由 `omrs:data`。
- 未迁模块的入口（`viewQ` / `qvSetContext` / `boardQuickAdd` / `lblChip`）在 `legacy.js`
  里做成**可选**：宿主没加载对应脚本时按钮不渲染，而不是点了报错。island 不能假设
  遗留脚本一定在——`npm run build` 之后这几个入口还会被第 7–10 期继续用到。
- 后端零改动。`GET /api/tree`、`GET /api/analytics`、`GET /api/export-review` 三个端点一行没动。
