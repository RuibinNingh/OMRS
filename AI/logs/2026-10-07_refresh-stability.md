# 2026-10-07 刷新闪动修复与 v2.3.5 发布

## 背景与范围

用户原话：「感觉刷新不够自然,每次刷新都会闪一下,似乎是加载有动画? 看看怎么回事,不委派子代理」；调查后追加「执行修复,完成后上线生产,推送GitHub,版本号+0.0.1」。执行者 Codex，完整模式，无子代理。

基线 main `ef92753` / v2.3.4，开工时工作区干净，生产源码为 `omrs-4f21255`。开发期间主工作区出现另一任务的 MCP 工具说明及协议改动，本批只抽取自身路径到 `codex/refresh-stability-v235` 发布候选，保留其他改动，不将它们纳入本次提交或部署。

## 行为变化

- 主工作台刷新和路由切换不再播放 260ms 的整页淡入、8px 上移与缩放。
- 同一草稿的手动刷新及每 2.5 秒轮询保留正文、已绘制裁图、编辑框、焦点与阅读滚动；返回相同数据不重建编辑器。
- 后台详情读取失败保留当前正文，显示错误与重试；首次读取和切换身份继续显示加载状态。既有 revision、迟到请求及未保存输入保护保留。
- 版本 v2.3.4 → v2.3.5。

## 影响文件

源码为 `assets/app/styles/base.css`、`assets/app/features/ai-review/drafts.js`、`drafts-view.js`；新增真实浏览器回归 `tests/e2e/ai_review_refresh.py`。同步审核中心、外壳、设计系统、前端架构文档；版本同步 `omrs/version.py`、`omrs_dashboard.html`、根 README、AI README 与 changelog；本日志和索引记录验收及发布。
