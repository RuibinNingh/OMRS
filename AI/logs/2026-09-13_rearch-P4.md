# 2026-09-13 架构改造第 4 期：样式与命名地基

## 变更摘要

组件化之前先把两处「越拖越贵」的东西收干净，本期不迁任何页面。

**token 层抽离。** 新建 `assets/tokens.css`，装浅色 `:root`、密度档
（`--pad` / `--gap` / `--row` / `--ctl` / `--fs*` 与 `html[data-density="compact"]` 的覆盖）、
`[data-theme="dark"]` 三块，外加原先散在 `assets/styles.css` 中段的 `--ib-role-*`
（收件箱框选标注色，固定不随主题，但它仍是「值」）。`styles.css` 里一条 token 声明都没有了，
页面按 tokens → styles 的顺序引入。

判据写进了 `AI/frontend.md` §13：选择器只有 `:root` / `[data-theme]` / `html[data-density]`
且大括号里全是 `--x:` 的是 token；带类名的是规则——所以 `styles.css` 末尾那段
「v1.7.0 深色对比度修订」留在原地不动。

**断点收敛成四档。** 原有 17 个不同的 `max-width`（520 / 560 / 600 / 640 / 720 / 760 /
768 / 820 / 860 / 900 / 980 / 1000 / 1100 / 1160 / 1180 / 1240 / 1500）收成
640 / 900 / 1180 / 1500；与 1180 互补的 `min-width:1161px` 一并改成 1181。

归档规则是**向上取整到不小于原值的最近档位**：简化布局提前生效只会更宽松，
向下取整则会让本该塌的布局在那一段继续撑着、有溢出风险。两处例外向下走——

- `.bd-layout` 的 1240 与 1180 设的是同一组 `grid-template-columns`，1240 那条只制造了
  1180–1240 之间「检查器被塞进 200px 窄列」的怪状态，删掉合并到 1180；
- 画廊列数阶梯（1180 → 4 列 / 980 → 3 列 / 768 → 1 列）向上取整会把相邻两档压到同一个
  档位、让 4 列那条变成死规则，故取 1180 / 900 / 640 保住三级阶梯。

**全局重名。** `assets/recommend.js` 与 `assets/recommend_v2.js` 各自定义了
`normalizeRecItem` 与 `recLabelsHtml`，v2 后加载静默覆盖 v1（两份实现恰好等价所以没出事）。
v2 的顶层声明统一加 `V2` 后缀。

**新增两个交付前必跑的检查。** `tests/check_globals.js` 扫 `assets/*.js` 的跨文件重名；
`tests/test_style_tokens.py` 守 token 归属与断点四档——`@media` 读不了 `var()`，
四档只能是注释契约，总得有人替它检查。

## 行为与兼容性

- 无 JS 行为变化；`normalizeRecItemV2` / `recLabelsHtmlV2` 只在 `recommend_v2.js` 内部调用，
  没有行内 handler 或其它文件引用它们。
- 视觉上有六处随断点移动而变化，都在预期内且不影响可用性（见「验证」）。
- 新增 `<link rel="stylesheet" href="assets/tokens.css">`，排在 `styles.css` 之前；
  顺序颠倒会导致深色档首屏闪一下浅色，`test_style_tokens.py` 盯着这一条。

- `python3 tests/test_style_tokens.py` → 7 例全绿。
- 全套 Python 与 JS 测试：除两处与本期无关的既有失败外全绿

  怀疑与本环境缺 woff2 导致文本度量不同有关，改动前后表现一致）。
- **真浏览器走查**（计划里的两条人工验收改成自动化，比手点更硬）：
  Playwright + Chromium 起真服务，5 个宽度（320 / 768 / 1024 / 1440 / 1920）×
  12 个页面 × 4 组主题密度组合 = 240 组，逐组测横向溢出并截图。
  - 横向溢出：改动前 4 处、改动后仍是同样 4 处（320px 的数据复盘 / 录入 / 设置，
    1024px 的数据复盘），一处没多；这 4 处是既有问题，本期不处理。

    （7 张），扣掉之后真正变了 6 张，均逐像素量过并人工看过：768 展示板由两栏挤压
    改为竖排、1024 仪表盘 KPI 条 5 格变 3 格、1024 历史时间线不再单独滚动、
    768 仪表盘行动卡改竖排、768 设置页优化区单栏、768 目录页树行收紧。没有破版。
