# 2026-09-13 架构改造第 5 期：引入构建，报告页首迁

## 变更摘要

跑通「新组件与遗留全局脚本共存」这条链路。选报告页是因为它最小、依赖最少、出问题影响面最窄。

**新增 `web/`**：Vite + Vue 3 单文件组件，产物输出到 `assets/dist/`。
入口 `web/src/reports.js` 只做一件事——`createApp(ReportsPanel).mount('#panel-reports')`，
其余标签页仍由 `assets/*.js` 渲染，`switchTab()` 继续管切换。

**删掉 `assets/reports.js`** 与 `omrs_dashboard.html` 里报告面板的静态结构和 `<script>` 标签。
面板位置换成挂载点，里面放一段「报告页尚未构建」的卡片：`mount()` 会先清空容器，
所以产物到位时它自动消失，缺产物时留在原地——仓库照常可运行，其余 11 个页面不受影响。

**新旧之间只有两条接缝：**

1. `switchTab()` 末尾派发 `CustomEvent('omrs:tab', {detail:{name}})`，组件用
   `web/src/legacy.js` 的 `onTab()` 订阅，用于懒加载。迁移前是 `switchTab('reports')`
   直接调 `loadReports()`；组件挂载发生在页面加载时，若改在 `onMounted` 拉数据，
   等于给一个可能整场都不打开的标签页发请求。遗留脚本不认识 island，
   island 也不该去 patch `switchTab`。
2. `web/src/legacy.js` 里组件调遗留全局的 `api()` / `uiConfirm()` /
   `copyTextToClipboard()` / `downloadExportResponse()`，按调用时从 `window` 取。
   **不另起一套请求层**——401 跳登录页只在 `core.js` 的 `api()` 里有一处处理。

**样式搬了第一刀**：报告页专属的 `.rp-*` 共 13 行从 `assets/styles.css` 移进组件的
`<style scoped>`；`.card` / `.cols` / `.btn` / `.input` / `.form-group` / `.sched-item` /
`.empty` 这些外壳类留在全局。`tests/test_style_tokens.py` 同时扫 `web/src/**/*.vue`，
组件里的媒体查询一样受四档约束、一样不许声明 token。

**产物入库**：`assets/dist/` 进 Git，部署机不装 node，线上更新仍是 `git pull` + 重启。
文件名固定（`reports.js` / `reports.css`）不带内容 hash，缓存刷新交给第 3 期的 `?h=` 指纹
——带 hash 的文件名需要一层 manifest 才能被 HTML 引用，而那行 `<script>` 是手写的。

## 行为与兼容性

- 报告页四项功能（列表 / 上传创建 / 浏览 / 删除）与迁移前一致；列表多了「加载中 /
  拉取失败 / 空态」三种状态的明确区分。
- `downloadExportResponse()` 新增返回值 `{fileName, size}`，向后兼容：
  四个遗留调用点一行没改，组件靠返回值渲染自己的状态行（它没有 `statusId` 可传）。
- `POST /api/report/create` / `/api/report/delete` / `GET /api/reports` 三个端点零改动。
- AI 报告提示词正文逐字沿用，只是搬到 `web/src/prompt.js` 变成纯函数。

## 验证

- `python3 tests/test_reports_island.py` → 10 例全绿。守的是**接线**而不是组件行为：
  遗留实现删干净（没有对已删函数的残留调用）、页面确实引产物、产物缺失时有可读兜底、
  `switchTab` 派发事件、`stamp_html()` 对缺失的 dist 原样放行且对存在的 dist 正常加指纹。
- 全套 Python 与 JS 测试重跑，除两处既有失败外全绿。
- 真浏览器走查重跑（同第 4 期的方法）：横向溢出仍是既有那 4 处；60 张截图扣掉动画抖动后
  只有报告页 5 张变了（变成兜底卡片），其余页面一张没动；控制台只有 `assets/dist/*`
  的 404，正是「尚未构建」这一状态的预期表现。

## 已知问题

   然后把产物一起提交。`web/` 源码没有在真 Vite 下编译过，首次构建可能要修依赖版本。

   `npm run test` 一起补。
