# 2026-09-29 OMRS 2.0.0 快速录入与字段安全

## 背景

按 `AI/plans/v2.0.0/exec-2026-09-29-p2.md` 执行。P1 已提交；开工时仍只有用户未跟踪的 `.playwright-mcp/`，全程未触碰。复核源码发现 quick 会合并 AI 返回的 labels，`.crw-pane label` 覆盖上传组件居中，题卡和新建题目会写旧页码。

## 行为变化

- 快速录入题图与答案图有独立上传、粘贴和缩略图；答案区默认折叠，有图后展开。上传 label 由组件自身控制居中，空图片与空状态不占空间。
- quick AI 请求显式传 `scope:"quick"`；模型不请求标记，服务端对白名单外字段过滤，前端不合并标记。识别绑定当前草稿、图片 ID 和字段快照；更换图片、重置、创建下一题或人工改字段后旧结果不覆盖。错因仅显示带题图文字引用的待核对候选，由用户主动采纳。
- 科目、分类、知识点采用共享可搜索建议层；分类按当前科目过滤，保留原生输入、键盘和中文输入法语义。题卡人工字段来源存入旧 inbox.db 的增量列，分类后台任务仍用 revision/epoch 防旧结果写回。
- 快速录入、题卡和新题 Markdown 不再写笔记本页码；旧 API 的 `note` / `form.page` 被忽略并返回 `deprecated_fields`。旧题正文、Ledger blob、收件箱旧列保留，普通正文编辑时移除活动 YAML 页码。反馈 note、草稿 note、图片说明未删除。
