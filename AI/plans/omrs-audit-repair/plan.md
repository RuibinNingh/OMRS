## 5. 关键技术决策

### 身份

内部关联键为 `question_id`；UID 只显示和兼容旧协议。新写请求发送 ID；混传 ID/UID 必须一致否则 409。Session 返回权威 entries，含 entry_id、question_id、uid_at_creation、当前 uid、source、availability、feedback_submitted；旧 uids/feedback_uids 为派生兼容字段。旧 UID-only Session 写入仅在本计划已绑定条目内解析。

旧 session.create 在创建提交时的映射绑定；bootstrap 无可靠证据时 unresolved，允许详情人工指定并追加 session.items_bind，不修改原提交。展示板稳定 ID 缺失禁止回退 UID。归档保留全部身份；UID、路径仅对 archived=0 唯一，去掉 INSERT OR REPLACE，从 Ledger 重建缓存。

### 创建及反馈

收件箱幂等键 `(item_id, reset_epoch, card)`；先保存预留身份、冻结内容摘要与产物信息。创建提交与 op_results 同 Ledger 事务；跨库失败只补 inbox 回执。相同重试返回原结果，不同摘要 409。后台扫描跳过未完成预留；启动先恢复。共享预留入口兼容草稿，不允许客户端指定内部来源。

labels 缺字段保留、[] 清空，旧库默认 []。前端批量与单卡互斥并在 await 后重查状态。反馈仅移除明确成功条目，失败保留判定/分数/备注；Session 刷新按身份合并。统一纯反馈转换，响应使用实际转换结果。元数据差量比较前后 Markdown blob，不用陈旧 YAML 覆盖未改的学习状态。

### 日期及生命周期

练习卡、普通推荐明确切换，不递归 load；每次 mount/read/round 身份在异步边界校验，卸载使旧读取失效；晚到写响应只刷新所属领域。sort:none 不排序。UTC 时间戳保留时区，业务日期默认 Asia/Shanghai；旧无时区记录不猜测未知精度。

### 配置

SQLite 活动配置为运行时事实源，config.json 为镜像和手改后重启的入口。完整验证候选配置，参数变化完整重放，在同一事务发布配置、投影、policy hash、revision、脱敏审计和待同步标志。提交前失败保留旧值；镜像失败明确 mirror_pending。启动先处理 pending；第三方冲突保留两份并在监听前停止；正常手改走相同发布。审计不存秘密。恢复和重放用当前 tuning，快照必须匹配 policy。

### 请求及存储

先鉴权和有界读取/解析，再短暂写锁。普通 JSON 默认 2MiB、旧图片 JSON 128MiB（可配置），原明确限额保留；大操作用暂存引用上传、每块16MiB，前端自动拆分。读取总期限普通30秒/大上传10分钟，无进展15秒；超量413、超时408、冲突409、繁忙503、真实服务故障500。PIN 按 Vault/IP 串行校验；HEAD 使用 GET 授权；图片统一附件受限解析。

生命周期租约覆盖 Web/MCP/CLI/后台磁盘段，跨进程文件锁。顺序：生命周期租约→写锁→模块锁→事务。网络、压缩和下载不持租约；任务保存 generation，恢复后旧任务不得写入。备份独占捕获全部 SQLite backup() 和文件 staging，带哈希清单，再释放屏障压缩/下载。

同文件系统目录恢复有持久 journal；committed 前故障回旧库，之后保留新库。恢复早于初始化/扫描；失败不能 mkdir 空库。成功更新世代、废止旧会话/确认/缓存，重建运行时。旧备份转换需校验，外部文件变化重试或明确失败。

### 容量及结构

普通追加只改受影响 SQL 行；历史修正/恢复/调参允许全量路径。全量流式提交与 SQL staging，取消累计全状态拷贝；快照最近2个加最多16个按需恢复点。删除快照仍可从 Ledger 重建，CSV 流式按需输出。

助手完成 Run 可靠落盘后移出内存，活动尾缓存每运行≤1MiB/1000条。对话/运行组/事件默认页30/20/200，上限100/50/500；游标跨完成/重启稳定，历史不截断。HTTP 单一注册表按领域分派，标准库启动；移除无消费者旧评分，统一日期工具，拆超大文档并保持索引。
