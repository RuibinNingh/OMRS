2. 凡创建、移动、外部新题或扫描产生新正文哈希，blob 与对应 commit 在同一事务写入，包括路径、YAML、正文同时变化。监听前回填只补安全路径、`_omrs_id`、文件哈希与投影一致的当前缺口，重复运行不新增提交；冲突跳过并报告。任何删除 Markdown 的路径先验证实际正文可从 blob 取回。跨题还原同时核验目标历史哈希和 blob 内身份；按运行撤销先预检全部依赖，中断按单项标记续做，外部修改则拒绝继续。
3. 收件箱 item 有持久 revision，旧库迁移幂等；人工与后台任务成功改变可见数据时递增。GET 返回 revision；用户更新、重置、丢弃和录入携带 `expected_revision` 与 `reset_epoch`。更新只修改显式字段；版本或代次不符返回 409 和当前版本、数据库不变；缺版本的旧标签页拒绝盲写。前端冻结字段 patch，`load()` 不覆盖待保存、请求中或拖动中的对象；后台模型返回后重读最新数据并校验代次及版本，auto 全链路传递 `reset_epoch`。冲突保留本地编辑并停止盲写，录入前 `flush()` 失败阻止提交。
4. 主服务监听前同步处理遗留 running 模型操作，管理 GET 保持只读。回退失败时主站仍提供其他功能，本地检测拒绝使用身份不匹配的模型并提示人工处理。录入页与训练历史分别标明“实际在线模型”和“训练目录默认模型”；助手会话加载用请求序号，旧运行结束不清掉新运行；标注 GET/保存/删除用 revision CAS，冲突时页面保留未保存框并提示核对；展示板读取 B 失败时保持 A 的选中项与内容一致。
5. 模型应用仍由人显式发起；缺少或未通过独立内容验收时明确确认并记录当时验收状态。服务端生成确认与审计身份，记录认证方式、会话 ID 和可信来源 IP，不存 PIN/Cookie，也不把共享 PIN 会话归为具体个人。对齐 16:59 operation 与可取得的主服务、反代日志；证据不足记“无法归因”，不猜测操作者、不自动切换在线模型。

## 5. 关键技术决策与边界情况

- 正文历史以可校验的题目身份和正文哈希关联；回填只处理当前文件能证明的内容，不为缺失旧版本编造正文。旧版本仅从哈希与 `_omrs_id` 均匹配的备份恢复；找不到则保留“不可取回”记录。
- 收件箱更新采用持久 revision 与字段 patch；用户更新、重置、丢弃和录入的 `expected_revision` / `reset_epoch` 是服务端 CAS 条件，缺少版本或发生冲突时拒绝写入。空 patch、重复请求、后台迟到结果和页面快速切换须有测试。
- 标注 GET 返回 revision，保存与删除携带 `expected_revision`；冲突时返回 409，并保留页面未保存框。正文还原的目标题历史哈希或 blob 内身份不符时，Markdown 与 Ledger 都不改变。
- 后台任务和模型切换以服务端持久状态为准；浏览器选择态、轮询态只显示结果，不推断在线身份。操作失败、服务重启和并发请求保留上一稳定状态与可追踪记录。
- 不自动应用未过验收的候选，不新训练模型，不改变训练数据分组或评测分母。服务端生成操作确认及身份信息，不信任客户端自报的操作者；真实生产回填和生产切换待单独授权。
- 对 16:59 operation 只做证据对齐；不能从主服务、反代日志归因时，明确记“无法归因”，不猜测操作者或切换在线模型。

## 6. 验收与验证

- 阶段 1 的只读 JSON 审计列出总数、当前缺口、文件/投影冲突、旧哈希缺口及可复核来源，不输出正文；三组隔离红灯测试能在基线失败。
- 正文创建、移动、外部新题、扫描、删除、增量回填、跨题还原和部分撤销续做的成功/冲突/中断路径通过定向 Python 测试；真实 Vault 无写入。
- 两个客户端交错编辑收件箱同一对象时，较晚的旧 revision 不能覆盖新值；前端保存失败和加载迟到时编辑仍可见，录入被阻止并显示原因。后台任务与人工修改交错、auto reset_epoch 也有回归。
- 模型恢复失败、在线身份不匹配、助手迟到响应、标注冲突和展示板换板后读取失败通过 Python、Node 及隔离真实浏览器主路径。
- 每期提交运行全仓 Python、Node、UI、对比度、相关 E2E、视觉和文档门禁；所有计数以任务日志中的实际结果为准，未运行项列明原因。
- 生产部署与真实 Vault backfill 获独立授权后，先取得一致性备份并核验哈希，再以部署前只读审计记录当时全部当前缺口，部署后将这些可安全回填的当前缺口降为 0，核对 Markdown 哈希不变、Ledger 校验通过、在线模型身份与页面一致。用户原话的 19 是较早盘点数，本轮复核时为 23，实际验收不能固定用旧数。若备份不可验证或文件身份、哈希与投影冲突，停止受影响数据写入。没有授权时计划停在本地可审查结果。
