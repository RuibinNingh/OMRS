# OMRS 入口背景配置

> **执行者**：Codex（完整模式）
> **目标**：让入口锁屏页支持黑洞预设和 Vault 共享的图片 / 视频自定义背景，并提供高斯模糊参数。

## 用户原话

- “我希望入口页的背景可以修改”
- “黑洞是一个背景”
- “在设置里面可以配置背景”
- “预设的有这个黑洞”
- “还有加一个自定义背景”
- “自定义的可以上传图片或者视频作为背景”
- “自定义模式提供提供预设样式,先加一个名叫高斯模糊的”
- “用户可以自己拉参数”

## 范围与决策

只作用于入口锁屏页，默认和失败回退均为现有黑洞 WebGL。配置写入当前 Vault 的 `错题/.omrs/config.json`，媒体写入 `错题/.omrs/entry-background/`，文件名由服务端生成。入口未登录时也显示当前自定义媒体；公共媒体接口只暴露当前选中的资源。自定义首版只有高斯模糊，范围 0–32px，默认 0px。图片 / 视频单文件上限 200MB，视频静音、循环、`cover` 裁切；设置页支持本地实时预览。

## 分期

1. 配置、分块上传、资源安全边界、入口渲染与黑洞回退。
2. 设置页入口背景卡片、统一状态 / 校验模块、预览和保存交互。
3. 后端 / Node / E2E 测试、文档、路由索引和门禁。

## 验收

默认入口显示黑洞；设置页上传合法图片或视频后预览、保存、刷新入口均一致；模糊滑杆越界夹到 0–32；切回黑洞不公开旧媒体；缺失 / 损坏 / 播放失败回退黑洞；超限、伪造 MIME、未知格式和路径穿越被拒绝；备份恢复保留配置与媒体；现有 PIN、跳转、主题和工作台行为不变。
