# 展示板改版：总纲

目标样式是用户给的 `target.html`（同目录，原名 `omrs-board-redesign.html`，自带示例数据与脚本，可直接用浏览器打开）。本计划把它落到 `assets/app/features/board/`，保留现有的数据与打印逻辑。

## 1. 保留什么

- 控制器与 I/O：`detail.js`（状态与操作）、`runtime.js`（真实 I/O 与单例）、`save.js`（按字段记脏的保存队列）、`print.js`（打印协调、纸面记录）、`preview.js`（常驻预览 iframe，按导出模板排版，保证与打印一致）、`drag.js`、`add.js`、`model.js`、`domain/board/*`。
- 服务端与数据格式不变：`boards.json`、`/api/board*`。示例里「关联标记」是板的持久字段；本期不改后端，关联的标记按板存浏览器本地（`localStorage`），同步仍走现有「按标记同步」。

## 2. 结构映射（现在 → 目标）

| 现在 | 目标 |
|---|---|
| 顶部状态条：板名、题数、状态芯片、说明、「打印全部 / 仅新增」、主按钮、下载、重新生成 | 主区板头：板名（点击改名）与更多菜单；次行文件夹、题数、备注、保存状态；右侧下载图标、「只印新增 / 全部重印」（有纸面记录且有新增时才出现）、主按钮文案随状态（打印 N 题 / 补印新增 N 题 / 重印全部 N 题） |
| 打印后「记录纸面」在状态条主按钮 | 板头下方确认条：「打印好了吗？确认后才会记下纸面」+「没打成」「已打印，记录纸面」 |
| 左栏：新建菜单、两级树 | 左栏：标题带计数与新建文件夹 / 收起按钮；「新建展示板」大按钮（N）；查找框；文件夹树（折叠、计数、更多）；板行两行：名称，题数 · 已印 N 页 · N 题未印 |
| 舞台头：纸面 / 列表 / 画廊三视图、添加、按标记同步、排序、清空、翻页、缩放、警告 | 纸面列工具条：「纸上 N 题 · M 页」（点开纸面记录浮层）、「N 题未印」「N 题已改动」（点击跳转）、翻页（上下箭头 + 第 x / y 页）、缩放、「版式」按钮。纸面始终显示，不再切视图；画廊视图删除 |
| 预览 iframe 直接放在舞台 | 灰色桌面上的纸：`.desk` 背景 + 纸张阴影；iframe 仍是唯一的纸面渲染 |
| 列表视图（行、留白芯片、详情、移除） | 右侧题目面板：标题「题目 N / 总数」、排序、添加题目；关联标记条（有新题时高亮 +「同步」）；停用提醒（移出）；表头「# · 题目 · 题后留白」；行 = 拖动柄、序号、UID、状态标签（已印 p.N / 未印 / 已改动 / 停用）、分类 · 难度 · 标记圆点、行内留白步进（− N行 +）；底部提示（Alt+↑↓） |
| 检查器「选中的题」 | 题目面板的详情层（从右滑入，固定头脚、正文独立滚动）：导航条含上一题 / 下一题与「打开题目」（共享题目弹窗）；题号与 UID、元信息、标记、题后留白卡（步进与预设 0/2/4/6/8 同一行、继承说明、锁定时禁用）、题面（答案先折叠）、练习记录摘要、底部「在纸上找到」「移出」 |
| 检查器「版式」 | 「版式」浮层（360px）：右侧留白滑块、题间留白、答案、题头显示、切割线与「第 N 题止」、锁定版式与说明 |
| 检查器「纸面记录」 | 「纸上 N 题 · M 页」浮层：已印、续排位置、已改动、清空纸面记录 |

## 3. 纪律

- 仍守 `tests/check_ui.py`：模板不写 `style=`、不写颜色字面量；示例的色值映射到 `tokens.css`（`s0–s3` → `surface-*`，`fg1–3`，`line / line2` → `border-1 / 2`，`pri` → `accent`，`ok / new / bad` → `success / warning / danger`），桌面与纸张阴影新增 `--brd-desk*` token；JS ≤400 行、CSS ≤300 行，按区域拆文件。
- 测试钩子沿用 `data-board-*`；常驻 iframe 的节点永不移动（morph skip），换布局时它的父节点也要固定。
- 窄屏（≤760px）按示例：左栏变抽屉（板头左侧按钮打开），板头换行，题目面板落到纸面下方。

## 4. 验收

- 桌面 1440 与手机 390 深浅四档截图与 `target.html` 同构；`tests/e2e/board.py`、`tests/e2e/board_picker.py` 通过并覆盖：保存不丢（快速连改后切板）、锁定版式时改版式要确认、打印 → 记录纸面 → 加题 → 只印新增的续排位置、行内留白步进、拖动排序、版式浮层、纸面记录浮层。
- `tests/app/board*.test.mjs` 全绿；`check_ui` / `check_contrast` / `check_docs --diff` 为 0。
