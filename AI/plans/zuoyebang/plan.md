# 作业帮搜题录入

执行者：Codex；运行模式：完整。用户已批准前端草稿并要求「按照这个做吧」，本计划记录实施边界。

## 用户诉求

- 「录入题目可以选择作业帮录入」；「移除\"AI草稿\"部分」「加上作业帮」。
- 「用户登录作业帮后可以调用摄像头」；后续收窄为「网页实时摄像头吧，先只做调用摄像头」。
- 「搜到的题目能直接提取为OMRS题目录入」。
- 「登录验收完了」「关于有效期,记录日志吧,到时候什么时候过期了也知道」。
- 「先弄一个HTML渲染器,渲染完毕后走AI识别的流程」。
- 「答案渲染不需要分块」「后端渲染固定宽度1080」「长度不限」。
- 「我需要能看到后端渲染」「按照这个做吧」。

## 目标与决定

录入导航以作业帮替换 AI 草稿按钮，兼容已有草稿跳转；审核中心、助手与 MCP 草稿能力继续由其现有模块拥有。新工作区具有会话配置、扫码登录、实时摄像头、图片上传搜题、独立候选选择、后台渲染及预览、AI 提取、人工核对和创建。

设备身份来自用户已验收的私有 direct-session.json，提供受鉴权的导入入口，不伪造注册设备或展示假在线状态。作业帮账号共用一份私有配置；会话日志只写白名单元数据，账号失效和签名失效分别观察，不凭网络错误判断过期，也不声称知道官方 TTL。

题干与答案各输出一张 1080 像素宽 PNG，deviceScaleFactor=1，高度由全文决定。答案不分块、分页或裁断；浏览器物理资源不足时整体报错并保留原始来源。HTML 清洗和图片下载在后端完成，Chromium 只加载本地可信资源；等待字体、KaTeX 和全部图片。前端可切题干/答案、HTML、适应宽度/100%、展开原图和查看渲染记录。

AI 复用 extract_region 的保真判断；文字公式可完整转录时保存文本，含关键信息的几何图等保存完整渲染图片。用户核对后才能创建。失败及截断保持来源和已完成结果，可重试；不自动补解答、不进行图文区域分块。

## 实施顺序与提交

1. 接入附件的纯 Python 签名、解码和账号协议，私有配置导入、短磁盘租约、脱敏观察日志和后台任务。
2. 清洗与本地化上游图文，真实后端 Chromium 固定宽度渲染；持久化来源与预览记录，复用 AI 和可靠创建操作。
3. 按批准草稿实现工作区，摄像头只实时预览，离页释放；保护异步响应与人工编辑。
4. 临时 Vault、随机高端口、真实 Chromium 验证主路径和失败边界；更新模块文档、任务日志、路由表、计划进度。

以上作为一个可审查的功能提交，包含实现、相关回归、文档与进度；不提交私有会话和渲染题目。基线 d8cfb7af8016c3d8a1a7e4bf56c3246efcd29c8d，开发在隔离工作树。

## 范围与停止条件

不做摄像头拍照取帧、连续搜题、细粒度分块、无关重构及草稿数据删除。生产重启、部署、systemd/Nginx 修改和推送没有授权。私有会话缺失不阻止独立实施；联网搜题和实体手机验收在最终报告注明实际状态。仅在目标冲突、不可判断的用户改动冲突或必须依赖用户的不可逆选择时停止。

## 验收与验证

- 导航中出现作业帮，审核中心草稿路径仍正常；缺少设备会话时说明原因，导入后可扫码及检查账号。
- 摄像头请求只含 video，优先后置；切工作区、离页、卸载及迟到授权都会停止 tracks。
- 多位置/多候选保持题干答案对应，切换候选不复用另一题的图片和提取结果。
- 真正的后端 PNG 宽1080，高度覆盖全部答案，末尾可见；重要附图和图片公式均完整加载，缺图明确失败。
- AI 提取不覆盖在途人工编辑，不补写，图形保留原图；创建幂等、回执可恢复。
- 日志无 Cookie、凭据和签名；errNo=6 不记账号失效；网络故障不改最后确认的有效状态。
- 运行相关 unittest、Node 回归、真实页面 E2E、check_docs/check_ui/check_contrast、组件浏览器门禁及前后视觉对比。

中断后先读 progress.md、git status 和 git log，再继续未完成步骤。交付说明使用中文，区分实际验证、未执行验证及部署状态。
