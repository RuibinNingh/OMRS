## 1. 已落实的保障

- [x] **增量与流式投影。** 普通追加只写受影响SQL行，不全链重放或清空全表；修正、恢复和调参走流式完整投影。快照与修正索引有界，按需生成CSV。行为与容量入口为`tests/test_data_runtime.py`、`tests/bench_data_runtime.py`。
- [x] **HTTP分域与统一边界。** `omrs/http/registry.py`集中方法/路径及策略，领域mixins处理业务。统一鉴权、正文限额、期限和错误分类，正文读取、模型网络及下载不占业务写锁；HEAD共享GET授权。
- [x] **全库一致性备份与恢复。** 独立SQLite在线快照与普通文件清单在生命周期屏障内捕获，ZIP在屏障外压缩。恢复journal、提交标记、世代和启动恢复可处理异常及进程中断；见`AI/backup.md`。
- [x] **稳定身份。** Session、展示板、选择、反馈与导出以question_id关联；归档不被活动UID唯一约束挤掉。旧条目无法证明身份时人工绑定，不猜测当前UID。
- [x] **助手历史有界且可完整读取。** 完成Run可靠落盘后移出内存；活动尾缓存最多1MiB/1000事件，对话、运行组和事件均稳定游标分页。
- [x] **统一验证入口。** `tests/run_gates.py` 包含 unittest、pytest 报告导出、Node、组件、打印、UI／对比度、E2E 枚举、升级、视觉及文档检查。必填参数的 E2E、辅助模块识别与独立服务门禁需按各模块说明显式核对，后续修复见本文件待办。现有调度页面回归见 `tests/e2e/schedule.py` 及 Node 调度测试。
- [x] **文档按职责分册。** 接口与数据分别使用`AI/api/`、`AI/data/`，模块只描述当前可验证行为，路由表由注册表生成。
- [x] **前端职责与纪律。** 原生ES Module按core/domain/features分层；设计token、DOM写入及文件体积由UI门禁约束。展示板导出任务、保存队列、纸面与预览token保持所属板和身份。
- [x] **MCP安全与原子草稿。** 实时校验Key权限、吊销、到期及Vault世代，独立数据库迁移串行、幂等回执可补齐。旧请求不写入恢复后的新库。

## 2. 后续可选优化

- [ ] **标记批量级联仍串行写Markdown。** 整批定义与题目写入已有 journal、事务回执和整体恢复，批次期间其它写入排队。当前上限为一千道实际受影响题，未承诺万题级延迟；若扩展上限再评估后台执行，不拆分用户一次批准的原子批次。
- [ ] **助手写工具跨进程重放的op_id协议。** 当前运行内串行执行与确认状态控制重复操作；若增加跨进程恢复，应为所有写工具建立持久操作回执。收件箱逐卡已有独立幂等合同，不代表所有工具都可任意重放。
- [ ] **纯图片题检索。** 已有题可按科目、分类及标记筛选，未建立通用图片内容索引；需要用户实际检索需求后单独设计。
- [ ] **展示板预览缓存仅保留最近一份HTML。** 切换多个大板仍需重建导出；可评估按内容指纹的小容量缓存，必须限制内存并核验纸面归属。
- [ ] **页面普通写入后仍有完整统计刷新。** SQL内部读模型已减少重复历史装载，但`reloadData()`在多个写点重新取全题统计；是否继续改成按领域补丁应基于实际交互延迟测量。
- [ ] **Markdown旧历史兼容解析。** 老题`# 历史`及旧后端响应仍可能使用兼容解析，无法证明没有消费者前保留；当前正式记录来自按稳定身份查询的SQL历史。

## 3. 全面实现检查待修项

- [ ] **R01｜中｜正式 Session 反馈重试重复计数（优先）。** `omrs/feedback.py:112–147` 只对聊天 attempt 去重；同一 Session／question_id／entry_id 的反馈在响应丢失后重试仍成功，历史与 attempts 从 1 到 2，可能提前击杀题目。领域复现、前端链路交叉审阅与独立 HTTP 均确认。修复应在事务内按正式条目去重且复用回执，保持独立即时练习的重复作答语义；验收包括响应丢失重试、批内重复及历史修正。
- [ ] **R02｜中｜助手／MCP 正文缓存与 hash 错配（优先）。** `omrs/agent/tools/read.py:22–37` 按投影 hash 缓存，却直接读尚未扫描的文件；外部改 B、扫描、恢复 A 后仍可能返回 B＋hash(A)。两个合成库复现，主代理独立重跑。修复应从对应 hash 的可信正文读取或校验后缓存；验收外部修改、扫描、恢复及重新读取的一致性。
- [ ] **R03｜中｜移动允许隐藏分类导致扫描后归档。** `omrs/question_ops.py:85–92` 的目录校验允许 `.omrs` 等扫描排除目录；移动返回成功，后续扫描归档题目而文件仍存在。领域与 HTTP 均复现。复用创建时对科目／分类的有效性约束，非法目标应在写文件或 Ledger 前拒绝；验收隐藏名、合法普通分类与扫描后可见性。
- [ ] **R04｜中｜移动抢占草稿预留 UID。** `omrs/question_ops.py:257–270` 仅以现有文件分配下一 UID，忽略待入库操作预留。合成草稿落盘失败预留后，移动其他题会占用其 UID，草稿重试持续报内容冲突。复用统一预留规则并核对并发／恢复，验收失败重试和移动都不抢占已有预留。
- [ ] **R05｜中｜即时练习提交中的编辑与落账不一致（优先）。** `assets/app/features/instant/index.js:169–210` 与 `view.js:79–85` 未在 submitting 时禁改判定／分数。真实浏览器延迟请求复现：服务保存错／4分，页面在等待中改成对／10分并将新值锁为已提交。应锁定提交快照或逐题对账，验收慢网、失败重试与 UI／历史一致。
