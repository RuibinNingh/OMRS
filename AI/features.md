## 特性一览

- **AI 助手**（在「设置 → AI 助手」里开启，需要支持工具调用的 OpenAI 兼容模型）：用对话找题、看哪块最弱、排复习、打标记；可粘贴、拖入或选择截图，让主 AI 直接看图或先读转述，并把题目录成独立草稿。手机 JPEG 上传时会整理相册尾数据或补结束标记，尺寸未超限时保留原图编码。改正文、记反馈按所选权限模式处理，题库写入可按运行撤销。在「审核中心 → 新题草稿」里可编辑、审核通过或丢弃；图片块可手动框选、转成文字或保留裁图入库。框选支持询问、自动或手动，共用截图和人工框会受到保护。可按图开启训练数据登记，入库后保存框选标注，训练图不会再次进入录入队列；「全文字也要框」允许题目先入库，再补独立训练框。设置中的「AI 录题方式」支持静默留草稿或在聊天中确认入库，侧栏显示待审核数量。
- **审核中心**：集中核对外部 MCP 与内置助手的业务写入。新题草稿可长期编辑和待审；助手正式改题、学习反馈、复习计划按所选模式批准或送审，MCP 与高风险展示板操作保持人工批准。正式题目提案可在原目标与字段范围内人工修订；助手和 MCP 还能提议替换、裁剪或移除题目／答案的 PNG、JPEG、GIF 配图，详情并排预览，批准后保留旧附件供历史恢复。过期或旧版本许可不能继续写入；自动执行的草稿、练习卡、报告和普通展示板修改也留下记录。
- **反馈录入**：按原题号列出计划条目，已录入与已归档条目只读，同名历史条目分别保留。待录题可分批判定、评分或仅本次跳过，停用和归档的题保留原号。处理完待办后，可在反馈录入或复习调度结单。

助手整个聊天主区域都可拖入 PNG/JPEG/GIF 图片；待发送、历史图片和草稿来源图可在站内预览、切换、缩放和下载。手机聊天使用紧凑头部与输入区，Enter 换行、发送按钮提交；长消息可按需展开；每次运行以「处理中」显示过程，完成后保持展开，用户可手动收起。输入区同时显示上下文与缓存用量。

长运行的历史记录可点一次「展开完整运行记录」读完并展开全部处理过程；读取失败后重试会继续已读部分。

助手可把已入库题目组成聊天练习卡，点卡片直接进入即时练习并保持题序。刷新可续练，题目移动后仍能找到；删除或停用的题会说明并跳过。重新练习会开新轮次，反馈重试不会重复计分，练习卡不创建正式复习 Session。

助手输入区同时显示上下文占用与缓存命中；运行详情把输入（未缓存部分）、输出和缓存列出，本次总量按三项相加。供应商未返回缓存或总用量时显示未知或已知部分，不把缺失数据当作零，也不把缓存与推理 token 重复计入总量。

「设置 → AI 助手」可调整每轮模型请求的最大输出 Token，默认 10240；实际可用上限仍由模型服务商决定。

「设置 → AI 助手 → 厂商兼容」选择「OpenAI（Responses）」时使用 Responses API；「通用」、阿里云百炼和 DeepSeek 使用 Chat Completions。地址填到 `/v1` 即可；旧会话可继续使用，连接测试也遵循所选协议。AI 识别和图片转述仍按独立的识图配置请求。

Responses 助手主动请求模型的推理摘要，实际返回后显示在思考步骤；同一对话保留原生推理上下文并使用稳定缓存键，缓存命中按模型服务的真实回执显示。聊天正文支持 Markdown 标题、表格、列表、公式和围栏代码块。

助手的平均输出速度按模型回执的输出 Token 和生成耗时统计，不计输入、缓存读取或图片辅助请求；实时估算标为 `≈`。长运行记录尚未读全时速度显示 `—`，展开完整记录后再统计。推理摘要保留分段，模型只在结束时返回摘要也可显示；未返回可读摘要时仍以实际回执为准。

「审核中心 → 新题草稿」采用并排核对：正文区阅读、编辑题目和答案，有来源图时在右侧通过缩略图选择来源并框选配图，裁框实时预览到正文，暂存或入库后保存。顶部选择器切换审核项，完整队列可展开；窄屏自动上下排列，放大框选、独立训练和转文字入口继续可用。题目信息先显示摘要，每次展开一个编辑框；块的「更多」可调序、插入、移动到另一部分或确认删除。MCP 草稿的完整图片也可手动缩放为局部框，暂存后保留所选范围，入库保存裁图，同时保留完整来源原图。底部格式检查可定位缺项，「入库并下一题」自动进入下一份待审草稿，版本冲突时保留本地修改。丢弃成功后保持「待审核」并继续下一份；队列清空后显示空状态，返回或刷新不会重新打开最后处理的草稿。

题目信息放在正文上方；正文实际宽度达到1000px时，题目与答案解析等宽并排，宽度不足时上下排列。来源原图保留，按剩余正文空间判断；两栏共用滚动和底部操作。缩放窗口不打断编辑，长公式可在局部横向滚动，只读详情也按相同规则排版。

助手建草稿可按阅读顺序混排文字和独立图块；若题干、图表与小问无法安全拆开，则优先保留完整题目图片。答案单独判断。

助手可在你确认后独立创建零题分类；新分类进入录入候选。助手也能按版本修订本对话的待审草稿，人工编辑过的内容会保留并交由你核对，修订不会自动入库。

「设置 → AI 识别」可控制 `deepseek-flash` 识图请求是否启用思考（默认关闭），保存后对图片提取、分类和助手图片转述生效；此项不控制 AI 助手主模型。

收件箱与草稿的区域文字提取可自动处理模型漏转义的数学公式定界符，并转换为可预览的公式格式，无需微调框位绕过这类格式错误；结果仍需人工核对，不完整或无效的识别结果继续提示重试。

| **收件箱录入** | v1.12.0 起「录入题目」页改为 **上传 → 处理 → 录入** 三步：手机在同一 Wi-Fi 打开 `http://<局域网IP>:8471/m` 直接投整张截图（sha256 去重）；手机页随主站浅色 / 深色设置切换。电脑端上传后可在收件箱网格按状态筛选、全选当前筛选图片并批量处理；已录入图片可打开关联题目。处理区可框题目 / 答案（可多题卡），点击「一键提取」让 AI 一次返回完整文本或不可提取原因，不能完整转写时保留裁图；结果出来后人工审核、修改文本，必要时用次要入口改存图片或切回文本；AI 框选（长图自动切片）、整图即题目、批量勾选处理；就绪的题卡填科目分类后一键写入题库。所有框位、AI 原框、采纳方式、转换决策留作训练数据，「AI 训练」页可看统计并导出 JSONL / YOLO 数据集。v1.13.0：框选可选提供方（多模态模型 / 训好后的本地检测服务）、每 N 张盲标作干净评估集、置信度达标自动提取（仍需人工审核后标记就绪）、上传即自动处理（需 Pillow）、超期丢弃图自动清理，自动策略在「AI 训练」页配置，提供方和连接统一在「设置 → AI 框选服务」。原单题表单保留为「快速录入」。收件箱数据集版式标签的新上传默认是「作业帮截图」（`zuoyebang`），可在处理页改为拍照/扫描、已裁好的题图或其他。后台提取文字完成时只刷新对应图片的结果，不中断当前框选；处理区「重置此图」可在提取卡住时清空当前截图的框选、识别结果和录入信息，保留原图重新开始。详见 `AI/inbox.md` |
| **框选标注页** | 为训练框选模型大规模采集数据的独立页：「录入题目 → AI 训练」点「打开标注页」在新标签页打开 `/annotate`。拖入截图或整个文件夹、`Ctrl + V` 粘贴都能批量上传（边传边标），每张图只框「题目」和「答案」，`Enter` 完成并跳下一张；`Q` / `A` 切角色、`C` 沿用上一张框位、`Ctrl + Z` 撤销，按 `?` 看全部快捷键。数据存在 `错题/.omrs/annotate/`，不进收件箱和题库；可导出 YOLO / JSONL，类别号与收件箱数据集相同，可直接合并训练。详见 `AI/frontend/annotate.md` |
| **题目录入（快速）** | 题面与答案截图可拖入、选择或粘贴，Markdown 原文与 Obsidian 双链分类可人工编辑；AI 按需补全科目、分类、难度和知识点，错因只提供待核对候选，不改人工标记，迟到结果也不会覆盖改过的字段或另一题图片。科目、分类与知识点有可搜索建议，分类按科目筛选；新题不再写笔记本页码。题目库可单题停用/恢复或删除并保留可审计归档记录 |
| **记忆算法** | 时间衰减 `time_decay`、熟练度状态机 `compute_mastery_update`、SM-2 间隔、易错因子 EF、统一优先级 `compute_priority`；未击杀且最近连错至少 3 次标记为 Leech（顽固题），答对后解除。一次高分答对即击杀，按 **7 / 21 / 60 / 120 / 180 天**分档复核；到期高分通过升一级，提前练习不延期。已击杀题低分答对退出击杀、3天后巩固，答错1天后重练；重新击杀从7天起步 |
| **即时练习** | 浏览器内直接做、在线翻答案、即时反馈（分数滑杆 + 对错）；聊天练习卡沿用同一页面，实际作答反馈仍入 Ledger，但不建立正式复习 Session |
| **反馈录入与错因** | 逐题判定和打分时，判定栏直接显示本题错因历史，可切到「记录本次」补记。错因独立保存，作答备注随反馈提交；换题和离页保护未保存草稿，已录入作答的题仍可查看错因 |
| **复习 Session** | 复习调度工作台自动加载推荐，支持建议 10 题、折叠筛选、chips、保留已选、列表/画廊题面预览和按科目均衡；已有计划可查看详情、进度、预览、导出并跳转反馈；详情支持删除调度（关联反馈一并撤销，可在历史记录恢复）。正式计划支持单题，旧单题 TMP 调用仍兼容 |
| **答题卡回填** | v1.11.0 起可把答题卡扫描（OMR）的正式结果 JSON 读进反馈页：选中该 Session → 在 OMR 识别详情页复制 `/api/v1/recognitions/<id>/result` JSON → 点「📋 读剪贴板填写」或直接 ⌘/Ctrl+V，按题号自动填对错与 0–10 主观分。只接受顶层 `recognition_id/template_id/mode/status/questions/unresolved` 协议，明确拒绝旧 raw/items、裸数组与包装层；`unresolved` 涉及的题不自动猜测，转人工处理。Anki 模式仍按 `questions[].answer` 映射为 OMRS 评分。 |
| **行动推荐** | 仪表盘顶部按当前题库状态排出「现在该做什么」：逾期、今日到期、未录反馈的 Session、顽固题、久未复习、最薄弱科目/分类等，每条带数字依据和一键跳转 |
| **目录** | 树状展示 `错题/` 的真实文件夹结构，每层标注题量、待复习、顽固题与平均熟练度；支持搜索、展开折叠、显示非题目文件，点题目文件直接开详情 |
| **用户标记** | 自定义名称与颜色的 `<=>` 芯片；录入、题库、反馈、推荐、即时练习和展示板均可添加/筛选，支持批量编辑、改名、删除、合并；默认不改变调度，设置 `priority_bonus` 后才参与优先级 |
| **展示板** | 板列表、常驻纸面和题目列表并列，可在行内调留白、打开滑入式题目详情，通过浮层调整版式、查看纸面记录和切换动效；动效支持渐隐渐显、左右滑页、抽纸及 100–800ms 时长调节，偏好保存在浏览器本地；持久化题目引用集合支持拖拽/菜单排序与按关联标记同步，导出左题右空 A4「错题集」；题栏与右侧留白默认各占可分配宽度的 50%，页面左右各留 10mm，不额外预留装订区或绘制装订导引线；打印后确认记录实际纸面几何，新加的题可**只补印新增**并沿用原纸比例接在空白处，页码始终是绝对页码 |
| **题库交互重设计** | 筛选抽屉、激活条件 chips、列设置、舒适/紧凑密度、命名视图预设和批量加入展示板/打标记/停用/导出 |
| **练习记录** | 画廊卡脚注的战绩带（一根竖条一次练习，绿对红错、高度是主观分，可关）与题目详情底部的记录模块（次数 / 正确率 / 平均分 / 平均间隔 + 主观分走势 + 明细）。v1.16.1 起数据来自 Ledger 投影（`GET /api/question` 的 `records[]`），题目 Markdown 里的 `# 历史` 只作老格式兼容 |
| **数据复盘** | 复盘页展示已击杀、击杀率、待攻克、练习覆盖率、休眠与复燃、累计击杀成绩及五档复核分布；题目明细可按状态、科目与关键词筛选、翻页查看及加入展示板。仪表盘提供统计/雷达/热力/散点/趋势；历史页按「学习与变更」「系统运行」分区，MCP 调用可筛选并追溯草稿及入库，学习记录保留显式修正模式 |
| **错题导出** | **自包含 HTML**（图片 base64 内联），分 **A4 打印版**、**展示板左题右空版** 与 **屏幕版**（卡片 + 判分 + 进度持久化）。错因与答案放在末尾反馈区（屏幕版折在「显示答案」后面），每题答案下面紧跟同题错因；未附答案时仍可显示错因。复习导出参数面板可独立开启题目区或反馈区的历史柱状图，并记忆上次设置 |
| **报告托管** | 上传/浏览/删除复盘报告，浏览器内直接查看 |
| **源码协助** | 设置页按源码目录和文件类型下载当前工作区的脱敏 ZIP，包含未提交源码且不依赖 Git；排除个人题库、附件、运行数据、日志、缓存和生成导出文件 |
| **日志导出** | 设置 → 服务与运行 → 导出日志，按类型、更新日期和文件名筛选后下载 ZIP；支持运行日志和 AI 请求日志及轮换文件。运行日志保留30天、合计最多64MiB；两类日志单文件8MiB、最多3份轮换备份，超限单条AI内容显式省略 |
| **外观** | 深色（首次打开默认，**暖石墨 Warm Graphite**）/ 浅色（编辑式暖色）切换；v1.15.0 增加**界面密度**（紧凑 / 舒适，默认紧凑）——设置页「外观」切换，收紧全站内边距、圆角、行高与控件高度；v1.7.0 重配深色对比度（三级文字与语义色达标、卡片改实色分层）；Ledger 时间线可按浏览器或设置页所选时区显示 |
| **数据可信** | 不可变 **Ledger 提交链** 是题目身份、学习反馈和 Session 等核心状态的事实源；内部读取 SQLite，CSV 按需导出，这些状态可重放还原 |
