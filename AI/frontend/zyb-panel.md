# 前端：作业帮服务面板

> **速查**
> - 职责：独立网关的状态概览、设备与账号操作、调用密钥、请求记录及搜题详情和访问策略
> - 入口：`services/zuoyebang/zyb_gateway/assets/index.html`、`panel.js`、`panel.css`
> - 不变量：状态来自网关真实观察；只读刷新不联系官方；敏感输入与一次性密钥不持久化
> - 必跑测试：`services/zuoyebang/tests/browser_acceptance.py`、网关单测、`tests/e2e/zuoyebang_gateway_integration.py --with-prefix`
> - 相关：`AI/zuoyebang-service.md`、`services/zuoyebang/README.md`、`services/zuoyebang/docs/api.md`

## 1. 页面与状态

面板是独立的无构建 HTML、CSS、JavaScript 页面，通过独立管理员会话登录。默认进入“服务概览”；导航还有“账号与会话”“调用密钥”“请求记录”“访问设置”。桌面采用左侧导航，窄屏将导航置于页面顶部并允许换行。主题跟随系统浅深色，图标为本地内联 SVG，不加载远程依赖。

概览显示设备配置、账号和签名三个状态。设备配置就绪只代表本地文件已保存；账号与签名分别使用 `observations.account` 和 `observations.signing` 的未知、有效或失效观察。导入后显示“待核对”。所有时间来自服务回执；官方 TTL 保持未知，仅展示最近成功、首次确认失效及两者区间。

主提示按以下顺序选择：状态读取失败、缺设备、签名失效、账号失效、缺账号凭据、待核对、最近官方请求失败、密钥状态读取失败、缺调用密钥、最近核对正常。网络、协议或上游错误保留此前成功观察。读取失败时显示失败提示并保留上次快照；刷新只读取本地状态，不触发官方核对、扫码轮询或自动重试。

账号摘要显示设备、凭据有无、最近核对与未知有效期。连接卡显示当前服务目录地址、有效密钥数与最近使用时间；地址保留反代路径前缀。已有密钥仅表明具备调用权限，实际连接仍需在 OMRS 设置中测试。最近活动使用最多五条账号观察，请求审计另有完整页面。

## 2. 设备导入与账号登录

设备 JSON、手动账号凭据与扫码均通过原生 `dialog` 打开。文件最大 256 KiB；也可展开粘贴区。选择文件时清除粘贴内容，编辑粘贴内容时清除文件选择，避免来源歧义。格式或接口错误在窗口内提示，保留输入供修正；成功关闭后清空输入。会话导入替换本地配置并结束旧扫码流程，后端契约不变。

扫码创建来自用户点击。用户使用官方 App 确认后手动“检查扫码结果”，无后台轮询。认证、取消、过期、缺失、替换或会话更换终态立即清空图片与流程编号，禁用检查和取消，并提供重新创建入口。五分钟仅是扫码流程期限。

关闭扫码窗口会清除本页图片，并向网关请求取消当前流程。创建响应迟到时先核对窗口世代，已关闭的窗口不会重新显示二维码，返回的流程会被取消。取消请求失败时明确说明尚未确认服务端取消。账号写操作期间禁止重复提交；窗口关闭与会话失效仍可清理本页信息。

## 3. 密钥、审计与访问策略

密钥窗口填写名称并生成，成功后只展示一次完整值，可复制或手动选择。关闭、退出、页面离开与管理会话过期都会清空完整值。生成期间关闭窗口，迟到回执只更新脱敏元数据，并说明完整值已丢弃，需要吊销后重新生成。密钥列表保留名称、ID、短前缀、指纹、创建与最近使用时间；名称用 `textContent` 构建，吊销前有确认窗口。

请求记录保留类型、来源、结果、密钥筛选与二十条分页；类型可选全部请求或搜题记录。列表显示客户端和对端 IP、方法、路径、HTTP 结果及耗时，搜题行提供“查看详情”。失败保留旧列表并给出提示，过时读取不会覆盖较新的列表。

搜题详情使用原生 `dialog`，显示时间、来源、双 IP、密钥 ID、耗时、年级、上传原图及返回内容。题干和答案以文字摘要显示，完整已解码返回数据可展开查看；官方 HTML 只在惰性 template 中提取文字，不挂载脚本或远程附图。原图使用管理员鉴权接口读取原字节并生成临时 Blob URL。详情或原图读取失败可手动重试；旧记录、鉴权前拒绝或已清理的内容明确显示未留存，不补造图片或结果。

搜题失败仍可回看已经通过校验的图片与固定错误回执；未通过图片校验的记录只保留安全错误。底部保留说明来自服务设置，默认最多三十天／一万条，详情内容合计256MiB；较早详情因容量清理后元数据仍可查看。保存与清理契约见 `services/zuoyebang/docs/api.md`。访问开关读取实际策略；首次开启外部访问需确认部署条件，只调整应用策略，限额只读展示。

## 4. 生命周期与可访问性

管理请求保留同源 Cookie、相对路径与 CSRF 头。会话世代使退出或失效前的迟到响应失效，并中止本页在途请求。搜题详情的窗口世代防止关闭后或打开另一记录后被迟到的内容覆盖；关闭窗口、退出、页面离开或会话过期时清空图片与结果，撤销 Blob URL，迟到图片不会重新显示。从浏览器历史缓存返回时重新读取管理会话。密码、设备 JSON、凭据、完整密钥、二维码与搜题内容均不写浏览器存储或 URL。

弹窗使用原生焦点约束和 Escape；关闭时焦点返回入口，入口因请求而暂时禁用时，在请求结束后恢复焦点。按钮支持可见键盘焦点，悬停样式只适用于支持悬停的精细指针。页面切换直接显示内容，无进入动画。

## 5. 验证

在网关目录运行单测和浏览器验收，截图输出设为隔离目录：

```bash
python3 -m unittest discover -s tests -t . -v
ZYB_TEST_EVIDENCE_DIR=/tmp/zyb-panel-evidence python3 tests/browser_acceptance.py
node --check zyb_gateway/assets/panel.js
```

浏览器验收使用临时私有目录、随机端口、合成设备和合成官方响应。默认连接可信本机 `http://127.0.0.1:9222`，可通过 `ZYB_TEST_CDP_URL` 指定，仅关闭本次 context。覆盖导入与独立失效、网络保留、密钥迟到与退出、扫码关闭及终态、审计分页、外部真实非回环拒绝、会话过期和焦点。浅深色分别检查 1280、780、390、320px 五页布局与实际文字对比度；截图不包含完整密钥、真实凭据或密码。

搜题详情另覆盖成功／失败、原件摘要、刷新、旧记录、读取重试、关闭与交错响应、图片读取时会话过期及退出；HTTP留存专项见 `services/zuoyebang/tests/test_search_history.py`。详情也在浅深色的1280、780、390、320px下检查布局与实际文字对比度，并保存隔离截图。

真实两项目联调入口及环境命令见 `AI/zuoyebang-service.md` §4。官方真实账号与生产入口需单独授权后验证，合成验收不代表官方有效期承诺。
