# 前端：作业帮整卷工作台

> **速查**
> - 职责：独立搜题页的原图、题框、逐题候选、完整预览和核对入库
> - 入口：`assets/app/features/zuoyebang/index.js`、`zyb.js`；路由 `#/zuoyebang`
> - 不变量：按上游位置绑定候选；原图与框位使用同一像素坐标；人工核对后才入库；离页释放摄像头
> - 必跑测试：`tests/app/create-zyb.test.mjs`、`tests/e2e/zuoyebang.py`、`tests/e2e/zuoyebang_service.py`、`tests/e2e/zuoyebang_gateway_integration.py`
> - 相关：`AI/zuoyebang.md`、`AI/zuoyebang-service.md`、`AI/frontend/create.md`、`AI/frontend/design-system.md`

## 1. 页面与来源

侧栏「作业帮」进入独立 `#panel-zuoyebang`，页面契约启用 workbench。桌面左侧为试卷原图、题框、题号和搜索／录入记录，右侧为当前题候选、题目／完整答案预览和确认按钮。大于1500px时给右栏更多宽度，题目与答案并排，隐藏内容切换按钮；760px以下原图与候选上下排列。录入页保留上传、处理、录入、AI 训练、快速录入五个工作区。旧的显式 create.stage=zuoyebang 动作跳转独立页。

默认上传模式支持选择、拖放 JPG/PNG/WebP；摄像头和上传共用「粘贴图片」及 Ctrl/⌘+V。原图不超过8MiB，上传／粘贴保留文件字节，通过 zuoyebang 用途的分块上传引用发送。文档级 paste 监听只在本页接管图片，不拦截表单文本粘贴；剪贴板权限失败提示键盘替代方式。更换图片或打开历史前，有未保存人工内容时先确认；切题则保存当前题的编辑副本。

大于1160px时，`.zyb-workspace` 通过 `flex:1; min-height:0; overflow-y:auto` 承接整屏外壳的剩余高度，左右栏作为同一工作区纵向滚动，原图下方记录可到达；确认按钮吸附在预览区底部。1160px及以下沿用文档滚动；两张完整长图分别在自己的预览框内滚动。

`zyb-camera.js` 使用 getUserMedia，后置优先、audio=false，期望1920×1440；按实际视频尺寸取帧为JPEG质量0.95。「拍照搜题」保留照片、释放摄像头并搜索；服务未就绪时仍可拍照并保留。HTTPS或localhost可用，拒绝授权、设备占用和无可用帧原位提示。切上传、离页、迟到授权均释放tracks；取帧和剪贴板异步读取校验页面、来源及输入代次。

## 2. 题框与逐题候选

搜题记录提供 image、regions、rotation；后端将上游坐标还原到上传原图，前端不再旋转。`zyb-paper.js` 复用 `domain/image-crop/process-canvas.js` 的 SVG 框、移动及八向缩放；画布留在 data-morph=skip 子树。原图尺寸、裁切、EXIF处理及坐标契约见 `AI/zuoyebang.md`。

点击题框或题号切换位置，右侧仅显示该位置的候选。初次搜索不预选候选；之后点题号可选择该题第一个候选，点候选自动生成预览。可隐藏题框；进入「调整题框」后才能移动或缩放当前框，修改保留在当前会话，用于「保留原题图片」，不改变上游候选关联或训练数据。坐标无效仍保留题号和可读候选，明确提示缺坐标；不补造框位，也不承诺上游覆盖整卷每题。

无匹配但有有效题框时可「保留原题图片」，按当前范围生成图片题卡；无任何题目位置时可保留整张原图。它复用既有识别、人工表单及幂等入库，答案为空，不生成解答。同一会话相同裁图范围复用记录和回执，调整范围后重新裁图。已有候选也可主动选择保留原题。

## 3. 预览与核对

候选渲染按360 CSS px手机宽度、17px正文排版，3倍输出题干与答案各一张1080px完整PNG；宽公式／表格仅局部适配，源图裁切保留实际像素尺寸。大屏并排预览；1500px及以下通过题目／答案切换。两区各有转义HTML与展开入口，共用适应宽度／100%比例，并显示尺寸及当前图指纹；长图独立滚动，不截断源文件。失败保留候选与重试入口；快速切候选串行执行，只绑定最后一次选择，已有渲染可复用。

「确认题目，开始识别」打开 `zyb-dialog.js` 管理的识别工作窗，首次对尚无识别结果的题卡启动既有AI提取。已有草稿显示「继续识别与录入」，已入库显示「查看已录入题目」，重新打开已有识别结果不会重复调用模型。窗口上方显示进度与就地状态，中间并排核对题目和答案，760px以下改为单列；各区可保留图片、修订文本或展开原图。题目信息在正文下方，底部固定暂存、识别／重试与录入操作，不随正文滚出窗口。

工作窗复用共享 `openModal` 的顶层隔离、焦点与减少动效规则；分类建议通过共享combobox客人浮层进入同一模态层，Escape先关建议，再关工作窗。暂存、Escape和遮罩关闭保留逐题草稿，在途识别继续；关闭后焦点返回确认按钮。提交中禁止关闭与编辑，失败原位显示且可重试，成功仍可查阅只读内容，必须由用户明确录入才创建题目。

缺少当前layout.version的候选预览保留旧图，并提供「重新生成手机版」。该操作复用已保存搜题正文生成独立render记录，不重新搜题；完成时保留最新人工表单、标记、两区正文、保存方式与版本，旧题草稿和旧PNG仍在。生成期间刷新或离页可继续恢复；失败保留当前旧预览和编辑。原像素裁图、已有创建预留及已入库记录不显示升级入口，不自动替换正式题目。

AI分别判断题干和完整答案能否忠实转录，必要图形或失败保留整图，可重试失败项。响应绑定render_id与编辑版本，不覆盖在途人工修改；分类合并使用共享 `domain/create-form.js`，科目／分类只补空，难度与知识点遵循既有人工字段保护。标记由人选择。创建期间表单冻结，核对后明确点击「录入 OMRS」，成功回执提供题库与展示板入口。

两区选择「使用文本」后默认预览，正文旁单按钮切换「源码／预览」，各区独立；源码可编辑，预览复用共享Markdown／KaTeX渲染器并保留换行。`zyb-text.js` 在两种视图将Markdown、Obsidian、HTML图片及内嵌data:image数据缩写为 `[图片 1]` 等占位符，不发图片请求；普通HTML转义。编辑保留占位符即可保留对应原文，删除占位符会删除该图片引用。真实正文仍存于section.text，显示映射仅为内存缓存，不进入提交。视图切换只保存section.view，不改变入库方式、脏状态或识别版本。宽公式在正文预览内滚动；已入库或提交中仍可查看两种视图，源码只读可复制。

## 4. 恢复与服务菜单

`zyb-state.js` 按渲染ID保存逐题草稿，按搜题／候选保存渲染引用；sessionStorage保存当前搜题、题号、候选、调整框、人工字段、正文显示方式、版本、任务及提取快照。`omrs-zuoyebang-review`只记录打开中的工作窗渲染ID；刷新／重新入页恢复同题窗口，不重发识别，主动关闭则清除此标记。同一候选重新生成预览时，工作窗随新渲染ID更新并保留最新人工内容。刷新由 `zyb-restore.js` 读取同源受鉴权记录和原图URL；恢复检查挂载代次，旧任务不覆盖新来源。试卷原图文件、凭据和二维码不存浏览器。缓存读取中离页再返回不会遗留忙状态。旧草稿没有显示方式时默认预览；已入库题卡只从草稿恢复显示偏好，正文始终取首次提交内容。

手机版是否可重新生成由记录的layout.version与当前mobile-360-v1比较，缓存引用不强制失效。重新生成的任务上下文保存旧render_id；成功后才更新当前候选引用，人工内容按完成时的最新草稿移交到新render_id，迟到结果不能移交到其它题卡。

历史同时列出最近搜索及渲染，打开搜索恢复原图和候选，打开渲染恢复该题及已提交回执；当前搜索的本地编辑保持。旧搜索没有归档原图时只显示已有候选，不将其它本地图片当作其原图。历史入口不承诺跨浏览器恢复未提交的人工草稿。

标题旁服务菜单由 `zyb-account.js` 管理外部点击、Escape、键盘、焦点和离页清理，提供服务设置、独立管理面板与有效期观察。账号、设备、扫码与Key管理仍由独立网关负责。配置切换清除旧账号观察，同配置暂态失败保留最近观察；链接通过共享domain校验，保留安全路径前缀、不携带Key。

## 5. 验证

`tests/e2e/zuoyebang.py` 启动临时Vault和随机端口，使用真实HTTP、摄像头模拟设备、Chromium渲染及正式合成题目创建；`zuoyebang_paper.py` 为其题框专项，覆盖选框、隐藏、移动、缩放、刷新、原像素裁切、逐题编辑、离页缓存与重复入库。网络边界用合成作业帮／AI，双进程网关脚本另验证真实签名解码链。八档截图检查浅深主题与320/390/1024/1440px，无真实账号或付费模型调用。

滚动回归在 `tests/e2e/zuoyebang.py` 使用真实滚轮检查1440、1161、1160及390px宽度，核对内容下移和确认识别按钮进入视口；不能只依赖自动滚入元素的点击断言。`zuoyebang_dialog.py`检查1500／1501断点、1920／2550px并排预览、独立长图滚动、模态分类建议与关闭焦点，以及320至1920px浅深主题下的操作可达性；识别、在途编辑、刷新和正式提交仍由同一主E2E串行完成。

同一E2E调用 `tests/e2e/zuoyebang_mobile.py`，覆盖旧预览升级入口的320/390px横溢、在途编辑与刷新恢复、只渲染不搜题、旧记录及PNG保全、已入库入口保护。后端专项验证中文输出字号、长公式／旧nobr／宽表格与3倍物理高度预算。

正文专项 `tests/app/zyb-text.test.mjs` 覆盖占位符逐字恢复、编号冲突、连续编辑及撤销、识别合并和正式内容保护；主E2E调用 `tests/e2e/zuoyebang_text.py`，验证真实公式排版、图片不加载、源码编辑、两区独立切换、刷新／切题恢复、完整原文提交及已入库只读。两种视图均拍摄浅深主题与320/390/1024/1440px截图；运行时审计与全站视觉脚本一致，排除可信KaTeX生成的公式节点行内布局，仅检查应用节点。

## 共享选择器契约

新题标记使用openCreateLabelPicker(anchor,{get,onSave})读取和保存当前表单标签，改动保留在草稿及正式入库内容中。快捷加板使用boardQuickAdd(uid,{anchor,direct})；普通点击以触发按钮定位选择器，Shift点击按最近使用板直接加入。
