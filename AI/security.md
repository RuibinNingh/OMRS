## 作业帮会话与渲染边界

作业帮设备会话、账号及二维码流程只在独立网关面板管理；OMRS旧导入／账号端点返回409，配置接口继承Web认证、POST来源及MCP隔离。OMRS私有service.json只保存连接与调用Key，目录0700、文件0600；账号观察只接收网关脱敏白名单，不含Cookie、签名、二维码挑战或上游原文。全库备份包含连接Key及既有私有目录，应按现有备份鉴权管理，不能把恢复旧文件当自动迁移账号。

独立网关搜题详情只向管理员Cookie会话开放，调用Key不能查看详情或原图；两类响应均 `no-store`，图片限定已校验的PNG/JPEG/WebP原件并设置 `nosniff`。只保存业务图片、年级和客户端回执，不复制认证头／Cookie、设备配置或异常原文。面板在惰性template中提取官方正文的文字，不加载远程附图、不执行HTML；完整数据用textContent显示。临时Blob原图在关闭、退出与会话过期时撤销，迟到响应不得恢复详情；权限与预算见 `services/zuoyebang/docs/security.md`。

上游 HTML 经标签/属性白名单清洗，去掉脚本、事件、任意样式和外部链接。附图接受任意域名的标准端口 HTTP/HTTPS 地址，不设域名白名单；每次请求及跳转校验全部 DNS 结果为公网单播 IP，并以核验 IP 建立连接、按原域名验证 TLS，防止 DNS 重绑定。不允许本机、内网、组播、其它非公网目标、其它协议或携带用户名／密码的 URL，下载不携带账号 Cookie。图片按字节、像素与总量限制验证。渲染 Chromium 仅由拦截器读取 OMRS 本地字体/MathJax3及可信配置，附图内联且不允许网络、任意 Vault 文件或外部公式扩展。HTML 预览仅作转义文本显示。

静态SVG附图在XML解析期间拒绝DTD、实体声明和处理指令，并限制节点数与层级；后续按SVG命名空间、元素与属性白名单检查。只允许当前图片内有效的片段引用，拒绝循环引用并限制引用展开规模；样式只接受静态呈现属性，禁止CSS转义、注释、外部URL及未知声明。脚本、事件、动画、外部图片、foreignObject、外来命名空间和未知元素均整体失败，不通过删除内容伪装成功。验证后的原字节仅以data图片加载，原有浏览器网络拦截与CSP继续生效；正文内联SVG仍拒绝。

搜题上传使用独立 zuoyebang 用途，验证原件为 PNG/JPEG/WebP、最多8MiB和4000万像素，不重编码；引用绑定操作者、用途、期限和 Vault 世代。网关与后台网络不持业务锁或长期磁盘租约，成功发布前核对世代与服务配置；切换后的失败只记原来源，不替代新服务状态。独立网关核对设备快照／扫码流程，取消或更换后迟到授权不能写回。摄像头仅在浏览器请求视频，优先后置，不请求音频或自动取帧；切页、关闭和迟到授权释放 tracks。

正文仅保留明确题库类和受限数值排版、分数线及display属性；脚本、事件、链接、危险CSS和外部TeX扩展均不能执行。MathJax3只加载可信本地配置、safe组件及字体。

## 1. 访问边界

日志清单`GET /api/logs`与下载`POST /api/logs/export`沿用普通Web鉴权，POST还校验来源；MCP凭据不能调用。服务端只读取固定运行／AI日志目录中的普通日志文件，拒绝路径穿越、目录和文件符号链接，不读取配置、业务数据库及维护文档。清单与ZIP禁止缓存；ZIP保留现有原文，不宣称已脱敏，页面明确说明AI请求日志含请求／响应内容。临时ZIP权限0600并在成功或失败后删除；文件范围、大小限额及冲突语义见`AI/api/queries.md`和`AI/api/mutations.md`。

本机通过 `127.0.0.1`、`::1` 或 `localhost` 直连时 API 免 PIN；若已配置 PIN，锁屏入口交给工作台的 `?unlocked=1` 跳转仍须有 PIN 会话。`lan_pin_exempt_cidrs` 可显式指定直连免 PIN 的私有局域网 CIDR；默认空列表。豁免仅看 TCP 对端地址，不适用于 Nginx 等代理请求。打开 `/` 或 `/login` 时先展示公开的锁屏入口；它只读取会话状态和当前入口背景，不加载题库数据。入口背景公开资源端点只根据脱敏配置解析当前一个服务端生成文件名，不能通过参数读取历史媒体或 Vault 任意路径；未选择自定义背景或文件缺失时返回 404。入口页的 PIN 表单提交成功后跳回带 `unlocked=1` 的同源地址，再由常规授权检查放行工作台；其他未登录页面请求跳转 `/login`，静态资源和 API 返回 401。启用 `allow_external` 前须设置 4–12 位数字 PIN 或配置免 PIN 网段；没有 PIN 时，非豁免远端仍拒绝访问。本机设置页可补设。`GET /api/auth/session` 与锁屏入口是未登录时可访问的入口。

服务端从 TCP 连接取得地址；只有代理的连接地址在 `OMRS_TRUSTED_PROXIES` 中，才读取其覆写的 `X-Real-IP` 和 `X-Forwarded-Proto`。默认可信代理地址为 `127.0.0.1,::1`，可用逗号分隔的环境变量覆盖。代理必须覆写 `Host`、客户端 IP 和协议头；缺少有效代理头时，非本机 Host 按远端处理。免 PIN 网段只允许 RFC1918 IPv4 与 IPv6 ULA，拒绝公网与不规范 CIDR。Nginx 配置见根 `README.md`。

## 2. PIN 与会话

PIN 的随机盐和 PBKDF2-SHA256 哈希存于 `错题/.omrs/auth.json`，不通过配置 API 返回。登录每个 Vault/客户端 IP 在15分钟内最多失败5次；同一键串行校验，等待校验最多2秒后返回503，其它IP不等此客户端的PBKDF2。失败次数在同一个原子校验段内更新，计数和闲置校验锁及时释放。设置页远端修改 PIN 或空闲时间时校验的当前 PIN 与登录共用同一失败计数。成功后服务端持有随机会话令牌的哈希，浏览器仅保存 `HttpOnly; SameSite=Strict; Path=/` Cookie；HTTPS 时追加 `Secure`。重启、恢复题库、退出、更换或停用 PIN 会使会话失效；只改空闲时间不注销会话，新上限在下一次请求时生效。尚未设置 PIN 时，免 PIN 网段设备可直接设置首个 PIN，已设置后远端修改一律须验证当前 PIN。登录页的 `next` 参数按 `new URL()` 解析，只接受同源地址，其余回到 `/`。

默认空闲时间为 30 分钟，可在设置页选择 5–240 分钟；绝对最长时间为 12 小时。后台轮询不续期，桌面和手机页只在点击、键盘、触摸、滚轮或滚动时按分钟节流调用 `POST /api/auth/activity`；监听挂在 `document` 的捕获阶段，页面内部滚动容器里的滚动同样计入。手机页 `/m` 遇到 401 时跳转 `/login?next=/m`，并停止处理剩余上传。框选标注页 `/annotate` 与主页同样经 `_authorize`（未登录的远端跳 `/login?next=/annotate`），页内请求 401 时由 `core/api` 跳登录页。远端 HTTP 登录成功后提示传输风险，同一会话确认一次；使用 HTTPS 不提示。停用 PIN 仅可在关闭 `allow_external` 后由本机操作。

## 3. 请求与报告

MCP Key 是独立凭据，不继承 PIN、Cookie 或管理员权限。密钥摘要存于 `错题/.omrs/mcp_keys.json`（0600），服务端每次协议请求重新校验吊销与到期时间。普通 Web 端口若收到 Bearer 或 `X-OMRS-MCP-Key` 会返回 403，不能借道调用正式题库、反馈、设置或草稿写接口；MCP 端点只注册固定二十四读十九业务写和一个技术准备工具。外部图片下载仅接受 HTTPS，解析前拒绝回环、私网、链路本地、保留和多播地址，禁止重定向并限制 8 MiB / 4000 万像素；下载固定经公共地址校验的 IP 并保留 TLS 主机验证，禁止 DNS 重绑定。HTTP 请求有总量/超时/每 Key 限流和并发限制；Key 生命周期用跨进程文件锁，管理响应禁止缓存。密钥、完整 URL 和签名参数不写日志。

所有 POST 在读取请求体前检查 `Sec-Fetch-Site` 和 `Origin`；跨站浏览器请求返回 403。无这些浏览器头的本地 CLI 请求仍可使用；远端请求还需有效会话。会写投影的扫描入口是 `POST /api/scan`，GET 返回 405。`GET /api/config` 不回显 `ai_api_key`，只给出 `ai_api_key_configured`。`GET /api/auth/session` 公开返回的 `instance_id` 不含秘密；`GET /api/status` 的 `listen_external` 同样不含秘密，但该接口仍沿用远端PIN会话授权，非豁免远端匿名访问返回401。

报告保存原始 HTML；浏览时加 `Content-Security-Policy: sandbox allow-scripts allow-downloads allow-popups`，脚本在不含 OMRS 同源权限的环境中运行。服务端仅给报告中的静态 `/api/image?name=` 附件文件名加签名链接，签名限单张图片、当前会话和会话时限；原始报告文件不改。远端题图响应禁止浏览器缓存，本机题图维持原缓存策略。源码包、备份和完整 Vault 路径仅供本机、显式豁免的直连局域网设备或已登录远端访问。

MCP 的同步草稿操作与 Web/助手共用主进程全局写锁，草稿初始化/迁移在内层模块锁内串行；图片下载不持有这些领域锁，事务不跨 `await`。

新建副作用前与创建结果封装前复查实时 `draft:create`，幂等缓存不能绕过处理中吊销、到期或降权；拒绝结果不泄漏草稿正文。鉴权不与网络送达原子化，合法提交后失效仅拒绝响应，不删除已提交草稿和原件。

工具发现和调用共用固定工具→scope 映射；每次发现按当前磁盘权限过滤。只读、仅建草稿客户端交错请求不会修改全局注册表，隐藏工具被直接点名时仍独立拒绝；旧 token 的 scope 和 SDK 共享描述缓存均不能覆盖实时 Key 权限。

MCP 运行记录存于独立 `runtime.db`，Web 列表、详情及学习详情中的来源关联沿用页面授权，运行接口响应设 `Cache-Control: no-store`；MCP 凭据在 Web 入口仍返回 403。记录只保存白名单筛选值、数量、服务端公开标识及密钥名称快照，不保存明文 Key、正文、原图、附件 URL、签名参数、自由客户端名称或原始异常。白名单文字中的 Key / Bearer / URL 片段也隐藏；记录写入故障只输出固定诊断消息。详情的动态文字由转义模板呈现，系统记录没有修正写入口。

get_question_image 只接受 UID 与图片下标，按共享 get_question.images 绑定该题声明的附件；查找仅在错题/附件及普通子目录，拒绝同名歧义、符号链接、重解析点和非普通文件，不解码 URL、不下载外链、不接受任意路径或回退到 Vault 根。固定目录/文件描述符或核对目录与文件身份后有界读取，防止路径替换；最多读取 8 MiB 加一个字节，原件累计解码限制为 4000 万像素与 100 帧。读取前及返回前复查实时 omrs:read，失效时不返回图片；运行库只记录脱敏 UID 和下标，不保存图片内容。

## 4. 题目文件路径

创建与移动题目时，科目和分类必须是单个非空目录名，不接受绝对路径、路径分隔符、`.`、`..` 或盘符路径。目标和来源文件均按真实路径确认留在 `错题/` 内，符号链接若指向根目录外也会被拒绝。题图加载失败时由浏览器事件监听器创建文字节点显示文件名，不使用内联脚本。

独立创建分类先折叠空白，拒绝 `.omrs`、控制字符、Markdown 链接符号和文件系统保留符号；目录与锚点拒绝符号链接，锚点不覆盖已有内容。科目索引写好后才创建新分类锚点，未完成的分类不会进入词表。`create_category` 为确认级工具；AI 草稿修订只接受本对话待审草稿的版本化白名单补丁，不能修改图片 SHA、身份、状态或训练字段。

## 5. AI 助手的权限边界

助手沿用现有访问控制：远端请求同样要 PIN 会话，远端用户与本机用户权限相同。模型能力由服务端工具注册决定，删除、设置、PIN、备份恢复、重启、源码导出没有工具。确认级写入按对话权限模式处理：manual 等人工决定，十分钟未处理转长期送审；hold 直接长期送审；danger 自动批准全部确认请求。模式只能由已授权 Web 请求设置，服务器记录设置来源与自动决定身份，模型没有切换工具；MCP 不受助手模式影响。聊天与中心共用 `ai_review.db`，票据绑定 operation_id、revision 与有效内容摘要，旧票据不能批准修订版本。中心批准可独立执行保存的提案，不重新调用模型；普通重启保留新长期待审，整库恢复仍废止未终结许可。题库内容作为数据，权限与持久审核是防线；模型密钥不回显，日志默认关闭。细节见 `AI/agent.md` §3。

中心正式写入除持久批准外，必须有内部执行上下文，绑定操作、版本、有效摘要、世代与原 agent_actor；伪造 applying 状态不构成授权。执行前核对当前助手开关、工具、对话归属、运行撤销状态和目标快照。危险模式同样受固定工具白名单、预算、目标版本及世代约束；自动同意不会恢复已失效提案。

确认入库工具 `commit_draft` 仅在 draft_mode=confirm 时注册，参数包含 draft_id 和 revision；预览与执行都重读配置、对话归属、review 状态和版本。确认期间被编辑或丢弃的草稿不能用旧许可写入。人工审核入口与工具共享草稿领域函数，HTTP 不接受伪造的 actor、uid 或来源。

草稿框选、提取、训练开关与清理继续走登录/同源及现有写锁；客户端不能指定任意文件或跨草稿任务。图级共享训练开关会改变关联草稿 revision，使等待中的旧确认失效。草稿清理只处理已到保留期的丢弃候选，聊天、活动/已入库草稿和训练引用均保护原图；训练登记不授予再次创建题目的权限。

## 训练评测复核

评测读取与图片端点沿用登录授权，图片按登记ID读取且校验根目录边界。复核POST沿用同源和全局写锁，SQLite事务检查revision后追加，不能覆盖历史或修改训练标签。付费评测仅在独立CLI中启动，读取助手渠道配置，密钥不写入产物或响应。正文里的指令视为待检查图片内容，不改变裁判规则。

## 受管检测服务边界

控制能力必须由进程环境OMRS_BOXDETECT_CONTROL指向部署者登记文件，精确绑定Vault、训练根、回环URL/端口及固定omrs-boxdetect.service；页面配置不能授予systemd能力，临时Vault即使继承环境也不能操作生产。后端只接受固定action列表，以argv调用固定systemctl，不接受网页传入命令、unit、任意模型路径或端口。候选以实验ID、权重与ONNX哈希校验，active限制在managed/snapshots内。

沿用登录与 Origin 校验，revision 及文件锁防止并发覆盖，request_id 防止不确定网络响应引发重复执行。操作身份由服务端从本机直连、局域网免 PIN 或 PIN 会话推导，仅记录认证方式、会话 ID 与可信来源 IP；客户端不能自报操作者，不记录 PIN 或 Cookie，也不把共享 PIN 会话归为具体个人。未过独立内容验收的候选需要请求中显式确认，验收状态随操作快照保存。

模型预检使用独立 systemd 临时单元，30 秒/768 MiB/2 CPU 上限，可用宿主机及 cgroup 内存不足 2 GiB 拒绝；不在主程序加载 ONNX。主服务监听前恢复中断操作，管理 GET 只读；恢复失败不阻断主站其他页面，但受管检测地址在每次请求前后核对已配置指针与实际服务健康身份，不一致即拒绝框选。部署账号须具备固定服务控制与受限临时单元启动权限；普通未登记部署显示不支持。

草稿修订必须同时有查询和 draft:update，所有来源待审核草稿可修订但人工保护优先。MCP 编辑身份单独保存，不能伪造原来源。正式题目只能通过同时具备 omrs:read 与 question:propose 的新提案入口请求修改；旧密钥不自动获得新权限。

## MCP 确认边界

确认/拒绝只从已授权 Web 会话进入，MCP 没有确认工具或 Web 借道权限。确认保存稳定 key_id 不保存明文；重新读取磁盘有效状态和当前 scope。快照变化、降权、吊销或密钥到期拒绝应用；原子领域回执已证明合法提交的中断操作则只恢复终态。完整请求存于独立 0600 的确认库，系统运行库只保存脱敏摘要。新增权限不默认授予旧 Key。创建正式复习计划须同时有 `omrs:read` 和 `session:create`，单独授予创建权限不能查询或创建；新建密钥仍默认只有查询与创建草稿，旧 Key 不自动扩权。调度提交前与返回结果前重新检查实时权限，幂等复用同样不得绕过降权、吊销或密钥到期。

正式题目提案绑定当前 UID、稳定 question_id 与完整 content_hash，只允许题目、答案、错因、补充备注、知识点、难度和已有标记。拒绝移动、删除、学习成绩、路径与任意字段；保留原图片字面引用、顺序和所属分节，不能增加图片或注入系统分节。中心修订仅限原目标与原字段，原请求摘要保持不变。中心待审不设时间期限；实际写入前仍复核当前权限、内容快照、世代与身份，助手聊天执行另核验原运行及等待期限。整库恢复废止新旧未结束审批。GET 不迁移记录、重放业务或把旧批准重新生效。

MCP导出图片复用受限question_images入口，不调用旧_find_image路径回退。快照下载只认稳定服务端编号、受Web授权保护，并校验普通文件身份、大小与SHA；导出目录和文件拒绝链接。导出HTML只用现有转义模板，快照不会回写纸面记录。

## 7. HTTP 文件与方法边界

HEAD 沿普通 GET 授权和路由，不调用标准库的当前目录文件回退。图片、报告图片授权和 HTML 导出共用 `question_images.attachment_path/read_attachment_image`：只接收附件内安全路径或唯一文件名，拒绝绝对路径、穿越、链接和重复解码。读取使用安全文件描述符或目录/文件身份检查，期间替换即失败；Web 读取已有大图不套用外部 MCP 单图8MiB限制。

无目录 FD 的路径读取分支使用独立 `os.lstat(entry.path)` 获取候选文件身份，再与打开后的 `os.fstat()` 比较；不能用 Windows 上可能返回零值 `st_dev/st_ino` 的 `DirEntry.stat()` 代替。目录／文件身份比较、重解析点与符号链接拒绝、读取期间属性变化检查仍然保留，不以跳过身份检查换取兼容性。

暂存上传的操作者、用途、Vault世代、期限和内容哈希在消费时再次验证。认证文件写入按租约→写锁→安全模块锁顺序，使用唯一0600临时文件原子替换。恢复调用 `invalidate_vault` 清当前Vault会话/失败窗口；正在等待的PIN校验锁保留到最后一位使用者退出。

## 标记整理审批

标记整理批准绑定定义摘要、稳定题目身份与正文哈希及级联引用集合；执行前重查实时来源权限，每次文件替换与事务提交前重查批准。人工修订不得扩大原目标集合。

## 标记整理工具

MCP 标记权限分 `label:write` 和 `label:delete`，默认关闭；合并与删除还须整理和查询权限。`stage_label_plan` 是服务端固定技术准备白名单，豁免业务审核但不豁免权限、来源或调用预算。

## 作业帮网关边界

连接配置只通过作业帮Web接口保存；独立service.json原子文件0600，目录0700，不进入通用配置、源码包或普通响应。Key留空保留、清除须明确字段，GET只返回配置状态与指纹；管理链接不携带Key。设备与账号凭据由独立网关持有，旧OMRS管理端点返回409，不读取或迁移旧会话。

网关地址接受合法根地址或安全路径前缀，拒绝穿越／编码／空路径段／查询及凭据。本地只准回环，公网外部默认HTTPS，可信私网须显式允许；元数据／链路本地等地址拒绝。DNS解析后固定核验IP，TLS按原域验证，不走环境代理或重定向。状态／搜题分别128KiB／24MiB，并发及整体超时限制见 `AI/zuoyebang-service.md`。错误和账号摘要使用固定／白名单字段，不暴露Key、Cookie或官方原文。同域反代覆盖XFF，并将独立Secure管理Cookie限制到服务路径。

网关调用Key与管理会话分离，本机亦需调用鉴权；请求历史包含socket来源／客户端及对端IP，可信代理规则由网关维护。OMRS服务切换及Vault恢复使迟到的旧结果失效，网络和渲染失败写回同样复查世代。前端旧观察只保留到同一非敏感配置身份，不能作为新网关的账号有效状态。
