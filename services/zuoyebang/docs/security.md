# 安全边界与运行预算

## 权限分离

- 默认绑定 127.0.0.1，allow_external=false；开关持久化，开启不会操作 systemd/Nginx/防火墙。
- 本机调用亦需有效高熵 Bearer Key。调用 Key 无管理权限，也无任何会话/凭据导出接口。
- 初始管理员秘密使用 secrets 生成，受限文件 0600，控制台只输出位置；密码为独立盐的 scrypt（N=16384,r=8,p=1）摘要。没有源码默认密码或测试后门。
- API Key 使用 32 字节随机熵，数据库仅 SHA-256 摘要；前缀/指纹不是原 Key。创建只响应一次，列表不含 Key。吊销对下一次认证立即生效；已进入官方搜题的在途请求不会被强行重复或自动重发。
- 管理 session 为 32 字节随机 token，数据库只保存摘要和过期时间；默认 1 小时、HttpOnly、SameSite=Strict、Path=/。HTTPS 公开 Origin 必须启用 Secure cookie。退出/rotate-admin 删除服务器 session。
- 同源 Origin 和独立 CSRF token 保护管理写接口。密码登录不要求既存 session，但要求同源 Origin。页面只在内存保存 CSRF，绝不把密码、设备凭据或 Key 写到 localStorage/sessionStorage。

## 网络与来源

Host 默认仅本机域名/IP + 实际端口，额外 Host 必须明确配置，禁止通配符；防止恶意域名通过 DNS rebinding 成为面板同源。公开 Origin 是独立配置，不从任意转发头推断。

默认 client_ip=peer_ip=socket 对端；忽略不可信 XFF。只对可信代理 CIDR 接受唯一、最多 16 项、1024 字节的 XFF，逐项严格 IP 解析，从右向左剥离可信代理。只要可信代理附带该头就必须校验；空值或首头为空的重复 XFF 返回 400/proxy_invalid，不能降级为本机来源。始终保留 peer_ip。**local 必须同时满足 socket peer 和解析 client 都为 loopback**；远端代理即使填 127.0.0.1，来源仍是 external；本机可信代理转发远端 IP 也成为 external。IPv4-mapped IPv6 统一按真实 IPv4 权限判断。

HTTPS/TLS 由明确配置的可信反代终止；本服务不内置生产 TLS。反代应覆盖用户注入的 XFF，后端只对反代开放，并设置公开 Host、请求字节限制/超时。不得因为 CLI 允许监听外部就省略 HTTPS、鉴权、反代来源限制。

官方 URL 固定，签名种子和账号 Cookie 只能发送至既定作业帮 HTTPS 端点；禁止 redirects，禁用环境代理，验证标准库 TLS 证书。无任意 URL 搜题、代理转发、图片转码或外网图片下载接口。

## 资源上限（默认）

| 项目 | 预算 |
|---|---|
| HTTP 活跃工作线程 | 32；满时无新 worker，429，审计 overload |
| 搜题并发 | 2，满时立即 429，无排队无限等待 |
| 每 Key API 频率 | 滚动 60 秒 60 次；SQLite 持久化 |
| 每 Key 搜题频率 | 滚动 60 秒 10 次 |
| 整个服务搜题预算 | 每 UTC 日 200 次；一旦进入官方尝试即扣一次，失败不自动退款/重试；换 Key 不能绕过总预算 |
| 每 socket peer 频率 | 滚动 60 秒 240 次（健康探针除外） |
| 登录失败 | 每 IP 300 秒最多 5 次；全局最多 50 次失败 |
| 请求体总读取期限 | 10 秒，read1 分块收紧 socket 剩余超时；拒绝 chunked、多 Content-Length |
| 搜题官方请求/读取 | 默认 50 秒；账号单次请求默认最多 30 秒；刷新/扫码确认可能含两次明确官方协议调用，不是搜题重试 |
| 图片 | 8 MiB，4000 万像素，单帧 PNG/JPEG/WebP，完整验证但原字节转发 |
| 设备导入 | 256 KiB，字段/header 校验，无任意官方地址 |
| 官方搜题 wire 响应 | 12 MiB，读取前 Content-Length 预检、流式累计硬上限 |
| 官方账号 wire 响应 | 2 MiB，同一有界读取器 |
| 累计解码 / 最终搜索 JSON | 各 24 MiB；gzip 多页累计预算，不是每页无限膨胀 |
| 审计 | 每次请求裁剪至最近 30 日且最多 10000 条；分页上限 100 |
| 观察事件摘要 | 最近 100 条，只有白名单元数据 |

CLI 可收紧/合理调整部分预算，有明确参数上限；不会更改图片 8 MiB/4000 万像素和官方 wire 响应硬限制。系统 DNS 解析依赖 OS 解析器；不承诺能强行中断任意内核/DNS 调用。HTTP/搜题槽位约束其并发，公开部署仍应反代限制慢头与连接数。这是单机单进程轻量网关，不是抵御公网分布式 DoS 的边缘服务。

## 持久化与发布

SQLite 私有目录 0700、数据库 0600；设备/二维码快照在该私有目录内，原子替换 0600，临时目录在操作结束删除。拒绝私有目录/祖先 symlink、私有文件 hardlink/symlink 和 SQLite 旁路文件链接。不要把私有目录给不可信系统用户或允许并行进程共享。

网络期间不持 SQLite/业务锁。操作先复制私有设备/二维码快照，返回后在短锁内检查会话世代、原字节/流程指纹；新导入或取消/替换流程使迟到的扫码结果返回 409，不覆盖新凭据。检查/刷新账号只发布账号文件和观察摘要，不回写它们携带的二维码快照，不能恢复已取消或替换的流程。不会在启动时生成假设备或重放搜题。

审计只保存固定路径/action、时间、IP、来源、key_id、稳定结果码和耗时，不保存 body、base64、图片、Cookie、Key、签名、二维码挑战或官方响应；未知路径归并以避免 path/query 注入秘密。默认 HTTP 控制台日志关闭。审计写失败响应 503，包括 HTTP 工作线程已满的拒绝路径；存储异常不输出原文。已经完成的管理变更可能已提交，客户端必须 GET 读回，不盲目重复写。

官方连接关闭或 socket 读写失败统一为 502/network，不自动重试，也不据此确认账号/签名失效。二维码成功、取消等终态在面板中禁用继续检查和取消按钮，只有重新创建二维码才能开始下一次流程。

SQLite 会复用空闲页，不每次 VACUUM；有限保留指逻辑条数/时间，不承诺每次删除后数据库文件立即变小。密钥元数据和管理员设置不受请求历史裁剪影响。第三方协议的真实账号、签名期限与官方兼容性仍需用户在获得授权后手工验证。

同仓HTTPS路径反代时，面板资源和管理请求保留外部前缀，Nginx剥离该前缀后转发到回环网关，并把zyb_admin Cookie从Path=/改写到/zuoyebang/；公开Origin仍只含协议／域名／端口。反代覆盖XFF，Secure、HttpOnly、SameSite=Strict与管理CSRF保持。
